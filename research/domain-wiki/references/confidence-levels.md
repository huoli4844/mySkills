# 置信度模型（5级）

## 概述

`confidence` 字段表示生成内容的置信度（0-1），`confidence_note` 字段说明置信度依据。**必须填写**，不能留空。

## 5级置信度

| 等级 | 数值 | 说明 | 使用场景 | 示例 |
|:----:|:----:|:-----|:----------|:------|
| 极高 | **0.95** | 定义可从原文逐字匹配，经人工复核 | 核心概念定义 | `confidence_note: "定义可从原文逐字匹配，经人工复核"` |
| 高 | **0.85** | 基于正文内容归纳，关键公式/结论可溯源 | 知识点核心内容 | `confidence_note: "内容基于正文归纳，关键结论可溯源"` |
| 中 | **0.75** | 操作步骤来自原文或教材标准流程 | 技能点操作步骤 | `confidence_note: "操作步骤来自原文或教材标准流程"` |
| 低 | **0.65** | 场景基于教材案例或实际工程经验构建 | 应用场景描述 | `confidence_note: "场景基于教材案例或实际工程经验构建"` |
| ~~极低~~ | ~~0.55~~ | ~~AI推断，缺乏原文直接支持~~ | ~~已废弃（代码不允许）~~ | — |

## 使用规则

### ✅ 正确用法

```yaml
# 核心概念（极高置信度）
confidence: 0.95
confidence_note: 定义可从原文逐字匹配，经人工复核

# 知识点（高置信度）
confidence: 0.85
confidence_note: 内容基于正文归纳，关键结论可溯源

# 技能点（中置信度）
confidence: 0.75
confidence_note: 操作步骤来自原文或教材标准流程

# 应用场景（低置信度）
confidence: 0.65
confidence_note: 场景基于教材案例或实际工程经验构建
```

### ❌ 错误用法

```yaml
# 错误1：confidence_note 为空
confidence: 0.95
confidence_note: ""  # ❌ 必须填写

# 错误2：使用"AI生成"作为依据
confidence: 0.85
confidence_note: AI生成  # ❌ 不能作为依据

# 错误3：置信度与说明不匹配
confidence: 0.95  # 极高
confidence_note: 内容基于正文归纳  # ❌ 应该是"逐字匹配"

# 错误4：使用已废弃的极低置信度（0.55）
confidence: 0.55  # ❌ 代码不允许，assemble_md 会拒绝写入
confidence_note: AI推断，缺乏原文直接支持
```

## 选择指南

### 问自己3个问题：

1. **能否从原文逐字匹配？** → 用 `0.95`（极高）
2. **能否从正文归纳，且关键结论可溯源？** → 用 `0.85`（高）
3. **是否来自原文操作步骤或标准流程？** → 用 `0.75`（中）
4. **是否基于教材案例或工程经验构建？** → 用 `0.65`（低）
5. **是否AI推断，缺乏原文支持？** → 不建议生成此类内容，若必须则用 `0.65` 并在 note 中说明

### 示例

#### 示例1：核心概念定义（极高置信度）

```yaml
concept: 直击雷
definition: 带电云层与大地上某一点之间发生的迅猛放电现象，叫做直击雷。
confidence: 0.95
confidence_note: 定义可从原文逐字匹配，经人工复核
source_from: 带电云层与大地上某一点之间发生的迅猛放电现象，叫做直击雷。
```

#### 示例2：知识点核心内容（高置信度）

```yaml
knowledge: 雷电防护系统组成
content_core: 雷电防护系统分为外部防雷系统和内部防雷系统。外部防雷系统防止直击雷...
confidence: 0.85
confidence_note: 内容基于正文归纳，关键结论可溯源
source_from: 直击雷主要会造成建筑物的损坏和室外人员伤亡，所以把防直击雷的系统称为外部防雷系统...
```

#### 示例3：技能点操作步骤（中置信度）

```yaml
skill: 避雷针安装
skill_description: 避雷针安装是外部防雷系统的基础技能，包括选择安装位置、固定避雷针...
confidence: 0.75
confidence_note: 操作步骤来自原文或教材标准流程
source_from: 直击雷的防护通常采用避雷针、带、线、网作为接闪器...
```

#### 示例4：应用场景描述（低置信度）

```yaml
scenario: 办公楼雷电防护设计
scenario_description: 某办公楼需要设计雷电防护系统，包括外部防雷（防直击雷）和内部防雷...
confidence: 0.65
confidence_note: 场景基于教材案例或实际工程经验构建
source_from: 雷电防护设计需要综合考虑多种因素，选择合适的防护措施
```
