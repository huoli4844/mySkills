# 每章写作规范（Chapter Writing Standard）

> 从第1章写作实践中提炼，后续每章严格遵循。

## 一、章前准备三要素

每章开始写作前，必须完成以下三个前置步骤：

### 1.1 提取大纲结构

```bash
# 用 parse_outline 确认本章结构
python3 scripts/parse_outline.py <大纲文件> -o /tmp/outline.json

# 提取本章节点
python3 -c "
import json
with open('/tmp/outline.json') as f:
    outline = json.load(f)
chapter = [c for c in outline['chapters'] if c['number'] == 'N'][0]
print(json.dumps(chapter, ensure_ascii=False, indent=2))
"
```

输出结构须逐级分解到最低层级，形成"章→节→子节→子项"的四级树。

### 1.2 确认写作任务清单

将大纲结构映射为写作任务清单：

```
第N章 标题 (N个任务)
├── N.1 标题
│   ├── N.1.1 标题
│   │   ├── (1) xxx     ← 一个子项 = 一个写作段落
│   │   └── (2) yyy
│   ├── N.1.2 标题
│   └── N.1.3 标题
│       ├── (1) xxx
│       ├── (2) yyy
│       ├── (3) zzz
│       └── (4) wwww
├── N.2 标题 (历史类：需分国际/国内两小节)
├── N.3 标题
├── N.4 标题
└── 本章总结 + 习题 + 参考文献 + 深入阅读
```

### 1.3 搜索KB获取素材

```bash
# 对每个叶节点搜索KB
python3 <kb-qa>/scripts/kb_search.py <KB_DIR> "搜索词" --format material --max-results 5
```

## 二、章首固定模板

每一章开头必须包含 **内容提要 + 学习目标**，不因章节类型而变化。

### 2.1 内容提要

```
## 内容提要

本章是{领域}的{定位}，主要介绍{内容概述}，使读者对{主题}有一个{效果}。
```

1-2段，回答"这一章讲什么、为什么重要、在全书中是什么角色"。

### 2.2 学习目标

7条量化目标，每条以可验证动词开头，且**每条目标必须对应一个或多个正文段落**（写入后验证可答性）：

| 编号 | 动词梯级 | 示例 |
|:----:|:---------|:-----|
| 目标1 | 认识到... | 认识到电磁干扰的严重危害 |
| 目标2 | 准确辨析... | 辨析EMD、EMI、EMC的区别 |
| 目标3 | 掌握... | 掌握三要素及数学模型 |
| 目标4 | 理解... | 理解系统内/系统间分层概念 |
| 目标5 | 了解... | 了解发展脉络和里程碑 |
| 目标6 | 建立...认知 | 建立研究内容的体系化认知 |
| 目标7 | 理解... | 理解学科特点和单位制 |

> 每章的目标数量严格7条，覆盖该章的主要知识点。

## 三、三本教材写作风格融合（核心方法论）

这是从路宏敏、梁振光、张亮三本已出版教材中提炼的融合写作方法论。每节写作时必须同时运用三种视角。

### 3.1 三本教材的核心优势

| 教材 | 风格定位 | 核心优势 | 适用的内容类型 |
|:-----|:---------|:---------|:-------------|
| **路宏敏** (详实型) | 案例驱动，学术叙事 | 极致的细节密度——每个事件都有具体年份、数字、组织全称、技术分析。长段落自然流畅。 | 历史叙事、案例描述、技术分析 |
| **梁振光** (系统型) | 结构清晰，体系完整 | 清晰的章节组织——每节有明确主题，从概念到历史到内容到特点递进。内容提要+结构导览。 | 概念定义、内容综述、体系构建 |
| **张亮** (实例型) | 问题导向，贴近读者 | 从日常电器现象入手——电视机+荧光灯、手机+CRT、吹风机+收音机。先讲现象再讲原理。 | 概念引入、机理说明、工程分类 |

### 3.2 融合写作模式：各教材视角逐层递进

每节写作时，按以下顺序依次运用三本书的视角：

```
第1层：【张亮视角】——用日常现象建立认知锚点
  → 不允许直接给定义。先问"你见过……吗？"
  → 从电视机+日光灯、手机+音箱、微波炉+WiFi等日常配对入手
  → 例子：路宏敏的第1章从13个案例开始，不是从定义开始
  
第2层：【梁振光视角】——给出系统的概念和定义
  → 在读者有了感性认识后，给出标准定义
  → 用清晰的结构分解概念的各要素
  → 配对比表或关系图
  → 例子：梁振光的内容提要+系统结构使读者知道"现在在讲什么"

第3层：【路宏敏视角】——用极致细节深化理解
  → 在概念建立后，给出详实的工程案例
  → 每个案例有具体的时间、地点、数字、技术分析
  → 案例不是"讲故事"，而是"做分析"
  → 每个历史事件附上组织全称、具体日期、技术参数
```

### 3.3 各内容类型的多教材融合模板

#### 3.3.1 概念定义类（如EMD/EMI/EMC定义）

```
【张亮部分】从日常现象引入
  以"打开电视机时荧光灯变暗"或"手机靠近音箱滋滋响"开头
  点明"这就是电磁干扰"
  建立读者第一印象

【梁振光部分】系统定义+结构分解
  给出标准定义（GB/T、IEC、IEEE多标准并列）
  用对比表或关系表分解概念要素
  提取共同核心（两个条件：抗扰度+发射限制）

【路宏敏部分】详实案例深化
  给出2-3个工程技术案例（含具体数字）
  每个案例后做技术分析
  用"这一案例说明……"提炼教训
```

#### 3.3.2 框架/要素类（如三要素）

```
【张亮部分】从现象提炼框架
  "刚才的手机+音箱例子中，手机是____，音箱是____，空间是____"
  自然地引出三要素，不需要生硬过渡

【梁振光部分】系统阐述
  逐一列出各要素并详细解释
  给出数学模型S(f)·C(f)·C(f)≥R_th(f)
  "式中"解释每个符号

【路宏敏部分】工程验证
  用多场景分析表展示框架的实用性
  每个场景有具体的工程背景
  附上对应的EMC设计策略
```

#### 3.3.3 历史叙事类（如EMC发展史）

```
【张亮部分】先问"为什么要了解历史"
  用1-2句话说明历史的价值
  然后进入叙事

【路宏敏部分】极致的细节叙事（核心）
  每段历史必须有：具体年份、组织全称、关键人物、技术参数、事件意义
  分阶段时每阶段标出起止年份
  关键节点加一句"为什么这个事件重要"的分析

示例（路宏敏的写法）：
  "1933年，国际无线电干扰特别委员会（CISPR——Comité International Spécial
   des Perturbations Radioélectriques）在法国巴黎成立。CISPR的第一次会议
   于1934年6月28日至30日在巴黎召开。"
  而不是：
  "1933年CISPR成立。"（这才是典型的"概括式"写法——错误）

【梁振光部分】对照表收束
  用国际/国内对照表整理时间线
  每个条目包含年代、国际事件、中国事件
```

#### 3.3.4 内容综述类（如研究内容）

```
【梁振光部分】先区分狭义和广义
  给出整体框架，让读者知道"地图上有哪些区域"
  用编号或Mermaid图总览

【路宏敏部分】逐项详述
  每一项2-4段，每段有具体的技术内容
  不是简单列举，而是解释"为什么重要"

【张亮部分】穿插工程实例
  每项内容配1-2个具体工程场景
  让读者看到每项研究内容的"用处"
```

### 3.4 实例对比：同一概念的三种写法

以"电磁干扰"这个概念为例，展示三本书的不同写法：

**张亮的写法（从现象到概念）**：
```
打开电视机时，室内的日光灯会出现瞬间变暗的现象，这是因为大量电流流向
电视机，电压骤然下降，利用同一电源的日光灯受到影响。还有使用吹风机时
收音机会出现"啪啦，啪啦"的噪声。原因是通过电源线传递而进入收音机，
以噪声的形式表现出来。像上面这种由一个设备中产生的电压/电流通过电源线、
信号线传导并影响其他设备时，将这个电压/电流的变化称为"传导干扰"。
```
特点：从日常现象出发，读者立刻有代入感，然后自然引出专业术语。

**路宏敏的写法（案例驱动，详实叙实）**：
```
1969年11月14日上午11时22分，由美国土星V火箭运载的"阿波罗"12号宇宙
飞船竖立在肯尼迪试验场的第39号发射架上准备发射。当时发射场的天气情况是：
在距地面240~250m及650~33000m之间有两层云，发射周围细雨绵绵……当计时
秒针走到第36.5秒、火箭飞行高度达到1920m时，从云层到火箭直到地面之间
发生了雷电现象……
```
特点：不是从"定义"开始，而是从"故事"开始。读者在阅读案例的过程中自然
建立了对EMC重要性的认知，后续的定义变成了"理所当然"。

**梁振光的写法（系统定义，清晰结构）**：
```
电磁兼容有两层含义：对于设备或系统的性能指标来说，是指"电磁兼容性"；
作为一门学科来说，则为"电磁兼容（学）"。电磁兼容及电磁干扰抑制技术
是随着无线电广播、通信技术的发展而逐步成长起来的。
```
特点：先给出清晰的定义框架，然后用结构化的方式展开。

**多教材融合写法的效果**：
```
第1段（张亮风格）：一个人打开电视机时，旁边的荧光灯管闪了一下；用吹风机
时收音机发出"啪啦"声；手机靠近CRT屏幕时图像开始抖动——这些日常经历
背后，都是同一个工程问题：电磁干扰。

第2段（梁振光风格）：电磁干扰（Electromagnetic Interference，EMI）是
指电磁骚扰引起的设备、传输通道或系统性能的下降。它与电磁骚扰
（Electromagnetic Disturbance，EMD）有着本质区别：骚扰是原因，干扰是
后果。两者关系可表示为……（下接定义、对比表）

第3段（路宏敏风格）：1969年11月14日，"阿波罗"12号飞船升空36.5秒时，
两道闪电击中了火箭，飞船的电源系统被破坏、导航系统失效、飞行平台失控。
事后分析表明，火箭及其火焰形成的导电体（总长约300m）人为诱发了雷电。
这一案例揭示了一个重要教训：在强电场环境下，大型导体可能成为雷电的"触媒"。
……
```
这样，读者的认知过程是：
  日常经验（张亮）→ 概念建立（梁振光）→ 深度案例（路宏敏）→ 真正理解

### 3.5 多教材融合的质量检查清单

每节写完后，检查是否同时具备三种视角：

```
□ 【张亮】本节是否从读者能感知的现象出发？
   （不是从定义出发，而是从"你见过……吗"出发）
   
□ 【梁振光】本节是否有清晰的结构和完整的概念定义？
   （对比表、关系图、多标准并列、条件分解）

□ 【路宏敏】本节是否有足够的细节深度？
   （具体年份、数字、组织全称、技术参数、事件分析）
   针对不同内容类型的深度要求：

| 内容类型 | 路宏敏式深度要求 |
|:---------|:----------------|
| 案例描述 | 每个案例有具体时间、地点、数字原因、技术分析、教训提炼 |
| 历史事件 | 每段有组织全称、成立日期、具体技术参数、事件意义分析 |
| 概念定义 | 引用3-4个标准原文，提取共同核心，分解为条件 |
| 框架要素 | 给出数学模型+"式中"解释，用多场景验证表，附策略 |
| 研究内容 | 每项2-4段，包含原理说明+工程实例+前沿方向 |
```

### 3.6 具体示例：历史事件的路宏敏式深度要求

| 要写的内容 | 概括式写法（错误） | 路宏敏式写法（正确） |
|:----------|:-----------------|:-------------------|
| CISPR成立 | "1933年CISPR成立。" | "1933年，国际无线电干扰特别委员会（CISPR——Comité International Spécial des Perturbations Radioélectriques）在法国巴黎成立。CISPR的第一次会议于1934年6月28日至30日在巴黎召开。" |
| 欧共体EMC强制 | "1996年欧盟强制执行EMC指令。" | "1996年1月1日，欧洲共同体12个国家和欧洲自由贸易联盟的北欧6国共同宣布强制执行EMC指令（89/336/EEC），凡不符合EMC标准的产品一律不准进入欧盟市场。" |
| 中国首个EMC标准 | "1966年我国发布第一个EMC标准。" | "1966年，原第一机械工业部发布了我国第一个干扰标准JB 854—66《船用电气设备工业无线电干扰端子电压测量方法与允许值》。" |

**原则**：每条历史事件必须包含"年份 + 组织全称（含英文） + 具体日期（如可能） + 事件经过 + 事件意义（为什么重要）"五个要素，缺一不可。

### 3.7 张亮式核心技巧：从现象到概念 + 工程实用导向

这是从张亮《EMC技术及应用实例详解》中提炼的两项关键写作技巧，与路宏敏的详实性和梁振光的系统性并列，构成多教材融合的第三根支柱。

#### 3.7.1 技巧一：从现象到概念（每个概念必须从日常场景出发）

**核心规则**：在给出任何专业定义之前，先用读者一定经历过的日常电器现象"搭桥"。

**标准结构**：
```
第1句：描述一个或一组日常电器现象
  → "打开电视机时，旁边的日光灯管会瞬间变暗一下"
  → "使用吹风机时，收音机发出啪啦啪啦的噪声"
  → "手机靠近音箱时，音箱发出滋滋的刺耳声"
  （选择读者99%经历过的场景，用3-4个短现象平行列举）

第2句：点明这些现象的共同点
  → "这些看似互不相关的小麻烦，背后都是同一个工程问题"

第3句：引出专业术语
  → "这个现象在工程上有一个专门的名字——电磁干扰"
```

**示例**（取自改写后的第1章）：
```markdown
打开电视机时，旁边的日光灯管会瞬间变暗一下——这是因为大量电流涌向电视机，
同一电源线上的日光灯"抢"不到足够的电压。使用吹风机时，附近的收音机发出
"啪啦啪啦"的噪声——这是因为吹风机的电动机在运转时产生了微弱的脉冲电流，
通过电源线传入了收音机。手机靠近音箱时，音箱发出"滋滋"的刺耳声——
这是因为手机的射频信号通过空间传播到音箱电路。这些都是每一个人在日常生活中
都曾遇到过的小"麻烦"，但它们背后指向的是同一个工程问题——电磁干扰。
```

**适用场景**：
- ✅ 概念定义类（EMD/EMI/EMC定义）
- ✅  框架/要素类（三要素）
- ✅ 机理说明类（传导/辐射干扰）
- ❌ 历史叙事类（用路宏敏式详实叙事更合适）
- ❌ 研究内容综述类（用梁振光式系统结构更合适）

**可用的日常现象库**：
| 现象 | 说明的EMC概念 | 涉及的耦合类型 |
|:-----|:-------------|:-------------|
| 电视机→日光灯变暗 | 传导干扰 | 电源线传导（共电源阻抗耦合） |
| 吹风机→收音机杂音 | 传导干扰 | 电源线传导 |
| 手机→音箱滋滋声 | 电磁干扰（一般概念） | 空间辐射 |
| 手机→CRT屏幕抖动 | 辐射干扰 | 空间辐射 |
| 微波炉→WiFi变慢 | 辐射干扰、频段重合 | 空间辐射（同频干扰） |
| 汽车经过→收音机杂音 | 辐射干扰 | 空间辐射（点火噪声） |
| 电梯启动→屏幕闪烁 | 瞬态干扰 | 电源线传导 |
| 静电→触摸电脑重启 | ESD干扰 | 接触放电/空气放电 |

#### 3.7.2 技巧二：工程实用导向（每个研究内容/技术必须配"有什么用"）

**核心规则**：在介绍任何研究内容或技术原理之后，必须立即给出具体的工程应用场景，让读者知道"这东西在现实中是怎么用的"。

**标准结构**：
```
[原理说明]  →  1-2段解释技术原理

[工程场景]  →  1个具体的工程问题场景
  以"例如，在产品开发中……"或"以一个具体工程为例……"开头
  给出参数、数值、操作步骤等具体细节

[应对措施]  →  具体的技术措施或解决方案
  列出实际工程中采用的手段、方法或器件
  区分不同条件下的不同做法
```

**示例**（取自改写后的第1章1.3节——研究内容）：
```markdown
**⑤ 电磁兼容性测量和试验技术。** EMC测量贯穿于产品分析建模、开发设计、
检验认证、干扰诊断等各个阶段……研究内容包括：EMI测量和EMS测量两大部分。

EMI测量分为传导发射（CE）测量和辐射发射（RE）测量——CE测量通常使用
线路阻抗稳定网络（LISN）和EMI接收机在9kHz~30MHz频率范围内进行，RE测量
则在天线、电波暗室和EMI接收机的配合下在30MHz~1GHz频率范围内进行。

各种测量设施各有特点和适用条件：开阔试验场（OATS）具有最真实的电磁环境
但受天气和背景噪声影响大；半电波暗室和全电波暗室在受控环境条件下进行
EMC测量，是目前使用最广泛的设施；TEM小室和GTEM小室适用于较小尺寸设备
的测量；混响室适用于大尺寸设备的高场强测试。

EMI接收机不同于普通的频谱分析仪——它内置了准峰值检波器和标准规定的测量
带宽，能够按照CISPR 16等基础标准的要求进行合规性测量。
```

**每个研究内容必须配的工程要素**：
| 工程要素 | 说明 | 示例 |
|:---------|:-----|:------|
| 频率范围 | 给出具体数值 | 9kHz~30MHz、30MHz~1GHz |
| 技术参数 | 给出量化和比较 | ESD脉冲上升时间亚纳秒级、场强40kV/m |
| 使用设备 | 给出设备名称 | LISN、EMI接收机、CDN |
| 操作流程 | 给出步骤 | 幅度筛选→频率筛选→详细预测→性能分析 |
| 适用条件 | 区分不同条件 | OATS vs 电波暗室、近场 vs 远场 |
| 数学描述 | 给出算法/方程 | 双指数函数描述ESD、MoM/FDTD等数值算法 |

#### 3.7.3 完整的张亮式段落模板

## 四、写作模式规范（每章强制遵守的12条军规）

以下12条写作规范从三本书中提炼，每章每节写作时必须逐一遵守。

### 军规1：概念必须先实例后定义

**规则**：给出任何专业定义之前，必须先用大量具体实例让读者建立感性认识。不允许"抽象定义先行"。

```
❌ 错误写法：
"电磁干扰（EMI）是指电磁骚扰引起的设备传输通道或系统性能的下降。"

✅ 正确写法（第2章2.1.1示例）：
"在EMC学科发展的早期，问题解决法几乎是唯一可行的方法。20世纪50年代之前，
电磁兼容尚未形成独立学科，工程界对EMC的认识主要来源于无线电干扰排除的实践经验。
在发达国家，问题解决法从无线电技术诞生一直延续到20世纪50年代。即使在今天，
我国许多制造厂商——特别是中小规模的电子企业——仍然普遍采用这种方法。造成
这一现状的原因是多方面的：产品开发周期短、EMC专业人才匮乏……"
```

### 军规2：每个案例必须有五要素

**规则**：任何工程案例或历史事件的描述，必须同时包含以下五个要素，缺一不可：

```
① 具体年份（含月份/日期更佳）
② 组织全称（含英文名称，首次出现时标注）
③ 具体数字（频率、幅度、距离、温度等量化参数）
④ 事件经过（不少于3-5句话的叙述）
⑤ 事件意义（"这一事件表明……"的分析句）
```

### 军规3：历史事件必须用"详实式"而非"概括式"

```
❌ 概括式（禁止）：
"1933年CISPR成立。"
"1996年欧盟强制执行EMC指令。"
"1966年我国发布第一个EMC标准。"

✅ 详实式（强制）：
"1933年，国际无线电干扰特别委员会（CISPR——Comité International Spécial des
Perturbations Radioélectriques）在法国巴黎成立。CISPR的第一次会议于1934年
6月28日至30日在巴黎召开，提出了两个核心问题：一是'可以接受的无线电干扰限值
是多少'，二是'如何测量无线电干扰'。"
```

### 军规4：设计方法必须用"三阶段对比"

**规则**：介绍任何设计方法或技术路线时，必须按"演进三阶段"结构组织，并使用对比表收束。

```
标准结构：
问题解决法（第一阶段）→ 规范法（第二阶段）→ 系统法（第三阶段）

每阶段的写法：
- 历史背景（什么年代、谁在用、为什么在当时是合理的）
- 核心逻辑（该方法的基本思路和工作流程）
- 优点（至少2条，说明该方法为什么能解决上一阶段的不足）
- 缺点（至少2条，说明该方法为什么会被下一阶段取代）
- 工程案例（1-2个具体数值或场景，展示该方法在实践中的应用）

收束：三阶段对比表（≥7个对比维度）
```

### 军规5：研究内容必须分"狭义/广义"

**规则**：介绍学科的研究领域或技术分类时，必须先区分"狭义概念"和"广义概念"，然后用编号分类逐项详述。

```
标准结构：
第一段：从狭义概念出发，围绕核心框架（如三要素）展开
第二段：从广义概念出发，扩展到跨学科的系统工程
第三段起：用编号（① ② ③ ……）逐项列出具体领域
每项写法：
  ① 领域名称——核心问题描述（1-2句）+ 原理说明（2-3句）+ 工程场景（1-2句）
```

### 军规6：对比表不少于5个维度

**规则**：所有对比表（概念对比、方法对比、类型对比等）的对比维度不得少于5个，最佳为7-8个。

```
标准对比维度模板（按需裁剪）：
本质 / 核心逻辑 / 介入时机 / 适用条件 / 优缺点 / 典型事例 / 成本特性
```

### 军规7：术语必须梳理"因果链"

**规则**：介绍术语体系时，必须梳理术语之间的因果关系，用"→"符号串联，并在段落末尾用一句话概括。

```
标准写法：
"电磁噪声→无用信号→电磁骚扰→（耦合途径）→电磁干扰→（需要）→电磁兼容"

然后在段末加入："用一句话概括这些术语之间的因果关系：______。"
```

### 军规8：数据必须有具体数值

**规则**：在技术描述中，不允许写"较高""较低""很大""很小"等定性描述，必须给出具体的数值或量级。

```
❌ 禁止："静电放电的上升时间非常短，峰值电流很大。"
✅ 强制："ESD脉冲的上升时间在亚纳秒量级（典型值<1ns），峰值电流可达数十安培，
频谱能量分布在几十MHz到几百MHz范围。"
```

### 军规9：习题必须标注学习目标和章节来源

**规则**：每道习题末尾必须标注 `（对应学习目标X，§N.N.N节）`。

```
格式：
N-1 题目内容……（对应学习目标X，§N.N节）
```

### 军规10：公式必须有"式中"解释

**规则**：每个工程公式之后，必须有"式中"段落，对公式中的每个符号做详细解释（含义+单位）。

```
标准格式：
$$
公式 \tag{N-N}
$$

式中，$P_r$ 为接收功率（W），$P_t$ 为发射功率（W），$G_t$ 为发射天线增益（无量纲），
$G_r$ 为接收天线增益（无量纲），$\lambda$ 为工作波长（m），$R$ 为收发距离（m）。
```

### 军规11：分贝换算必须覆盖"定义→换算→公式→例题→速查表"全链条

**规则**：所有涉及分贝（dB）的内容，必须按以下全链条展开：

```
① 数学定义（功率比和电压比的公式，含推导说明）
② 便利性解释（至少2个为什么用dB的理由）
③ 常用绝对单位列表（dBW、dBm、dBμV、dBμV/m、dBμA等）
④ 单位换算公式（P_dBm = P_dBW + 30, U_dBμV = U_dBV + 120）
⑤ 50Ω系统电压-功率换算（U_dBμV = P_dBm + 107，含推导）
⑥ 例题（至少2个，带"解："步骤）
⑦ 速查表（常用比值如2:1、10:1、100:1对应的dB值）
```

### 军规12：频谱知识必须配9频段表

**规则**：涉及电磁波频谱的内容，必须按9个频段逐一列出（ELF/VLF/LF/MF/HF/VHF/UHF/SHF/EHF），每个频段标注频率范围、波长范围和EMC工程关注重点。

### 3.1 概念/定义类（§N.1 常见）

```

[深化理解] 多个段落
```

### 5.2 教材学术叙事风格（Real Textbook Writing Style）

> 🔑 **来自会话教训**：之前尝试了"六步教学法"(Step 1经验锚定→Step 6自检巩固)的写法，被用户判为"越写越差"——因为真实出版教材**从不使用显性教学步骤标记**。正确做法：研读已出版教材（如路宏敏、梁振光、张亮三本电磁兼容教材），学习它们的**学术叙事风格**，而非自创教学框架。

**三本参考教材的风格分析**：

| 教材 | 风格定位 | 开篇方式 | 段落特征 | 人称 |
|:-----|:---------|:---------|:---------|:-----|
| **路宏敏**《工程电磁兼容》 | 详实学术型 | 案例驱动，像讲故事 | 信息密集长段落 | 第三人称"人们" |
| **梁振光**《电磁兼容原理技术及应用》 | 系统讲授型 | 内容提要+直接进入主题 | 中段为主，结构清晰 | "读者"视角 |
| **张亮**《EMC技术及应用实例详解》 | 工程实例型 | 从日常电器现象入手 | 描述通俗，由浅入深 | "我们" |

**三本教材的共同特征（必须遵循）**：

| 维度 | 正确做法 | ❌ 常见错误（会触发用户强烈不满） |
|:-----|:---------|:----------------------------------|
| **叙事风格** | 第三人称客观学术叙述（"人们""读者""我们"） | 第二人称"你"对话式（"你有没有过这样的经历"） |
| **段落** | 信息密集型长段落，一段讲清楚多个层次 | 刻意拆成极短段落，一句一行 |
| **定义处理** | 定义融入自然叙述当中，不设独立"定义框" | 单独划出一个"定义"子节，像维基百科条目 |
| **教学步骤** | 靠信息密度和自然过渡来"教"，没有显性标记 | "Step 1: 经验锚定""自检巩固："等标签（用户说"你越写越差了"） |
| **自检** | 通过章末习题完成，不内嵌 | 在每个概念末尾嵌"请你自己判断……" |
| **结构** | "大纲即法律"——标题与大纲逐字匹配 | 自行修改标题、增减章节 |
| **案例** | 详细叙述经过后自然带出分析 | 用"EMC启示："等显性标记隔开 |

#### 5.2.1 正确写法 vs 错误写法对比

**定义处理**：

```markdown
❌ 错误写法（显性教学标签+第二人称）：
"你有没有过这样的经历？手机靠近音箱，音箱发出滋滋声。
这个现象叫电磁干扰。
电磁干扰是指电磁骚扰引起的设备性能下降。"

✅ 正确写法（第三人称学术叙事，定义融入段落）：
"电磁干扰是与电气、电子设备相伴而生的。设备在正常工作时，
往往会产生一些有用或无用的电磁能量，这些电磁能量可能影响
处于同一电磁环境中的其他设备或系统。在深入讨论电磁兼容之前，
必须首先厘清两个密切相关但本质不同的概念——电磁骚扰（EMD）
和电磁干扰（EMI）。"
```

**段落长度**：

```markdown
❌ 错误写法（刻意拆短，一句一段）：
"电磁干扰是指电磁骚扰引起的设备性能下降。
它强调的是后果。
EMD强调的是可能性。
EMI强调的是实际后果。"

✅ 正确写法（信息密集型长段）：
"电磁干扰是指电磁骚扰引起的设备、传输通道或系统性能的下降。
我国国家军用标准GJB 72A—2002对电磁干扰的定义更加直接：
任何能中断、阻碍、降低或限制通信电子设备有效性能的电磁能量。
干扰（Interference）一词强调的是'实际后果'——性能下降已经发生。"
```

#### 5.2.2 第二人称"你"的使用红线

**绝对禁止将"你"用于说明性/教学性文字**——这是"辅导班讲义"和"正式教材"的分水岭。

| 使用情景 | 允许？ | 示例 |
|:---------|:------:|:------|
| 章首内容提要 | ❌ 用"读者"替代 | "使读者对……有总体了解" |
| 正文论述 | ❌ | "电磁干扰是指……"（客观陈述） |
| 定义解释 | ❌ | "这种因果关系的理解是学习……的逻辑起点" |
| 过渡句 | ❌ 用"我们"替代 | "在讨论了基本概念之后，下面来回顾发展历程" |
| 习题题干 | ✅ | "回顾你日常使用的电子设备……" |

#### 5.2.3 段落写作准则

- **信息密集**：一段承载2-3个信息层次，不一句一换行
- **自然长度**：核心论述100-300字，过渡30-80字，不人为控制等长
- **逻辑内嵌**：因果、转折、递进关系在段落内部通过关联词完成，不另起段
- **首句定调**：段落首句是"主题句"，点明本段核心论点
- **引证融入**：引用标注放在句末【路宏敏，§1.2】，不影响行文流畅

```
## 八、已验证的章节写作模式（从实战中提炼）

### 8.1 "从路到场"渐进式耦合分析模式（第4章验证有效）

适用于电磁耦合/能量传输类章节。教学结构按照"电路级→分布参数级→场级"的认知顺序递进。

**第一层：电路模型（KVL/KCL基础）** — 从基尔霍夫定律出发。共阻抗耦合 $U_2 = U_1 Z_{12}/(Z_1+Z_{12})$ 直接来自KVL分压公式。电容性耦合从KCL相量模型导出。电感性耦合从法拉第定律导出。目标是让读者用已学的电路知识理解耦合的物理本质。

**第二层：频域扩展（频率特性分析）** — 引入频率变量。电容性耦合 $U_2 = j\omega C_{12}R / [1 + j\omega R(C_{12}+C_{2G})] \cdot U_1$ 是一阶高通特性，推导转折频率 $f_c$ 和低频/高频近似。让读者理解"低频耦合弱、高频耦合强"的分段规律。

**第三层：分布参数与过渡（传输线效应）** — 当导线电长度超过0.1λ时（对应>30 MHz），集总参数模型失效。引入传输线效应、反射、驻波。30 MHz是EMC测量中传导发射和辐射发射的分界频率——让读者理解为什么这个频点是分界。

**第四层：场理论（近远场+波阻抗）** — 从电基本振子场方程的三项推导近区（$1/r^3$）和远区（$1/r$）划分。波阻抗 $Z_w = \sqrt{\mu_0/\epsilon_0} \approx 377\Omega$。

**层次衔接**：电路(KVL) → 频域(一阶高通) → 传输线(分布参数) → 场(麦克斯韦)。用频率升高作为贯穿各层的驱动轴。**不违反原则**：不在第一层引入麦克斯韦，也不止步于电路级。
```
