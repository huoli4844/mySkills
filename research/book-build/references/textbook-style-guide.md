# 教材风格指南（Textbook Style Guide）

> 来自对三本已出版教材（路宏敏、梁振光、张亮）的写作风格分析。

## 一、三本教材的写作特征

### 路宏敏《工程电磁兼容第3版》

| 特征 | 描述 |
|:-----|:------|
| 开篇方式 | 案例先行，第1章1.1节全部是13个详细案例 |
| 案例写法 | 有时间、地点、具体数字、像讲故事（"当计时秒针走到第36.5秒……"） |
| 段落长度 | 长段为主（300-600字），信息密集 |
| 定义处理 | 定义融入叙述，没有独立"定义框" |
| 历史叙事 | 4个子节详细展开（萌芽→组织→体系化→中国） |
| 人称 | 第三人称客观陈述，用"人们""设计者" |
| 内容量 | 第1章77,843字节 |

### 梁振光《电磁兼容原理技术及应用第2版》

| 特征 | 描述 |
|:-----|:------|
| 开篇方式 | 内容提要+直接进入主题 |
| 结构 | 清晰系统，每节一个核心主题 |
| 段落长度 | 中段为主（100-300字） |
| 定义处理 | 定义+实例+分析，无显性教学标记 |
| 历史叙事 | 2阶段简要叙述 |
| 人称 | "读者"视角，客观 |
| 内容量 | 第1章22,008字节 |

### 张亮《电磁兼容EMC技术及应用实例详解》

| 特征 | 描述 |
|:-----|:------|
| 开篇方式 | 从日常电器现象入手（电视机+日光灯、吹风机+收音机） |
| 语言 | 通俗易懂，描述性强 |
| 实例风格 | 有产品名称、有现象描述、有解释 |
| 人称 | "我们"视角 |
| 内容量 | 第1章18,381字节 |

## 二、共同特征汇总

1. **第三人称学术叙事**——不用"你"对话，用"人们""读者""我们"
2. **信息密集型段落**——一段100-300字，不刻意拆短
3. **无显性教学标记**——没有"Step 1""自检巩固""要点一"等标签
4. **定义融入叙事**——不给独立定义框，自然融入段落
5. **自检通过章末习题**——不内嵌自检环节
6. **案例分析融入自然**——不设"EMC启示："显性标题，用"事后分析表明……"自然带出

## 三、写作风格checklist

写作每章前对照此表确认风格正确：

```
□ 全文第三人称？(禁止"你")
□ 段落信息密集？(不做一句一段)
□ 无显性教学标签？(无"Step N")
□ 定义融入叙事？(无独立定义框)
□ 自检仅限章末？(无内嵌自检)
□ 案例分析自然融入？(无"启示："标题)
□ 大纲标题逐字匹配？(不改一个字)
□ 有设问/因果过渡？(不直接切换话题)
```
