# 管线输出质量基线（2026-06-12 实测）

> 新旧管线对比基线。重构后必须做一次全端到端测试（第1章），与旧管线输出逐项对比。

## 测试条件

- **数据**：EMC 教材第1章"绪论"，4本参考书
- **旧管线**：v3.4 时代，写作大纲由 Agent 手动填充，章节正文由 Agent 逐节写作
- **新管线**：v3.7.0，写作大纲 `generate_outlines.py` 生成骨架 → Agent 按 15 板块填充 → Agent 按写作指南写正文

## 关键发现

1. **写作大纲质量决定章节正文质量**：新管线的大纲（68KB/619行/15板块）远优于旧版（20KB/255行/5板块），直接导致正文质量提升。
2. **大提纲不一定好**：新管线大纲案例数多（67 vs 21），但章节正文案例质量对比时，旧版第1.1节因开篇手法更好反而更吸引人。关键不在数量，在**每节指南的具体程度**。
3. **模板改进影响所有章节**：一次 `templates/chapter-writing-guide-template.md` 的改进（增加5项结构化要素要求）比修补单个章节正文更有价值。

## 附录：第1.1节质量差距根因

旧版第1.1节（用户认可）vs 新版第1.1节（需要改进）：

| 维度 | 旧版（好） | 新版（弱） |
|:-----|:----------|:----------|
| 开篇 | 3个日常场景（电钻/吹风机/手机）→ 读者秒懂 | 麦克斯韦+赫兹历史叙述 → 距离感强 |
| 案例 | 7个（丰田/iPhone12/5G C-band/波音787/大疆/京沪高铁/心脏起搏器） | 1个（苏格兰风电场） |
| 术语辨析 | 8维对比表（EMD vs EMI） | 仅文字说明 |
| 教学手法 | 设问引导框 + 教学视角框 + 第一粒纽扣比喻 | 纯叙述 |

**根因**：旧版写作大纲的§1.1指南明确指定了"3个日常场景开篇"、"EMD vs EMI 8维对比表"、"教学视角框"等具体元素。新版大纲的§1.1指南只给出了通用的要素清单，缺少这些经实战检验的教学手法要求。这一差距已在 v3.7.0 的 `templates/chapter-writing-guide-template.md` 中通过"结构化要素 5 项"和"开篇方式 3 选 1"补上。
