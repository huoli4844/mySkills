# 写作大纲查疑补漏工作流

## 问题

连续写多章写作大纲时，Agent 在后期章（通常第8章以后）会系统性跳过以下板块：
- "教授级写作专项要求"中的4张表（设问引导句/工程直觉提示/教学视角句/前后呼应句）
- "参考文献"和"深入阅读"
- "习题"（有时只写"略"）

原因是注意力资源在"每节写作指南"上耗尽，写到末尾时偷懒。

## 检测

写完一批大纲后，运行结构完整性扫描：

```python
import os
for ch in range(1, 14):
    path = f'output/写作大纲/writing-guide-ch{ch}.md'
    if not os.path.exists(path): continue
    with open(path) as f: c = f.read()
    ok = all(x in c for x in [
        '### 设问引导句', '### 工程直觉提示',
        '### 教学视角句', '### 前后呼应句',
        '### 习题', '### 参考文献'
    ])
    print(f'Ch{ch}: {"OK" if ok else "GAP"}')
```

## 补充原则

**只补实际缺失的，不盲目扩充体量。** 不要因为某章体量比 Ch2 小就强行扩充——先检查6项结构是否完整。如果结构完整但体量小=题量结构限制（如 Ch5 搭接技术只有8子节 vs Ch2 的20子节），属于正常。

补充标准：
- 教授级专项的4张表：每表3~5条，内容与该章主题直接相关
- 习题：8题（3基础+3进阶+2思考）
- 参考文献：4~7篇（含核心参考教材 + IEC/GB/GJB标准 + 国际经典教材）
- 深入阅读：2~4本（含推荐理由30~50字/本）

## 补入位置

- 教授级专项：补在 `## 章末板块` 之前
- 参考文献/深入阅读/习题：补在章末板块内，`## 9分之星要求` 之前
