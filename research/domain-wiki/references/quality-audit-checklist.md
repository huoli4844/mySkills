# 知识库质量核查清单（8 Requirements Audit Checklist）

> v46.2: 基于 EMC 教材知识库全量审计经验总结。用于知识库构建完成后或内容大修后的系统性质量验证。

## 审核流程

```
全面审计 → 分级定级(P0/P1/P2) → 并行修复 → 抽样验证 → 0断链确认
```

## 8 项核查清单

### 1. 所属领域、层级解读、步入认知阶段、核心概念图谱

| 检查项 | 目标 | 验证命令 |
|:-----|:-----|:-----|
| 所属领域 | 所有节点 `### X. 所属领域` 非空非"无" | `grep -rl '所属领域.*无' 30_核心概念/ 50_知识点/ 60_技能点/ 70_应用场景/` |
| 层级解读 | 场景 SP KP 的层级解读非"无" | `grep -rl '层级解读.*无' 70_应用场景/` |
| 认知递进链 | Mermaid 流程图非空，节点数≥3 | 人工审查 + `grep -c 'graph' **/*.md` |
| Bloom对齐矩阵 | 场景 KP SP 有完整表格 | 搜索 `Bloom.*对齐矩阵.*无` |
| L3 domain_overview | 无"待补充"无`{{ }}`模板变量 | `grep -c '待补充\|{{' domain_overview*.md` |

### 2. 学员浏览应用场景时可一键跳转对应关联知识点

| 检查项 | 验证命令 |
|:-----|:-----|
| 场景→KP wikilink 存在 | `grep -c '支撑知识点' 70_应用场景/*.md` |
| wikilink 指向真实文件 | `for link in $(grep -oP '\[\[\K[^]]+' scene.md); do test -f "${link}.md" || echo BROKEN; done` |

### 3. 知识点包含：举例、解释、基本概念、原理支撑、技能要求、技能目标

| 字段 | 对应模板位置 | 检查方式 |
|:-----|:-----|:-----|
| 举例 | `### 3. 典型例题/案例` | 非空，≥2个案例 |
| 解释 | `### 1. 理论基础` | 非空，≥100字 |
| 基本概念 | `### 1. 理论基础` | 含术语定义 |
| 原理支撑 | `### 2. 核心推导过程` | 含 Mermaid 图或公式推导 |
| 技能要求 | `### 5. 技能要求` (v46.2新增) | 2-4条具体技能 |
| 技能目标 | `### 6. 技能目标` (v46.2新增) | 2-4条可达成目标 |

### 4. 单个技能点配套 1～2 个实例

```bash
# 统计每个SP的案例数
for f in 60_技能点/*.md; do
  count=$(grep -c '案例[0-9]' "$f")
  [ $count -lt 1 ] && echo "❌ $f: $count 案例"
done
```

### 5. 应用场景各流程节点用一句话描述，并配套整体解答

| 检查项 | 位置 |
|:-----|:-----|
| 典型工作流程 Mermaid | `### 1. 典型工作流程` |
| 流程说明 | `### 案例操作流程说明` (≥200字) |
| 整体解答 | `### 2. 典型应用案例` 含完整方案 |

### 6. 概念、知识点明确标注「解决的问题」(v46.2新增)

| 节点类型 | 模板位置 | 检查方式 |
|:-----|:-----|:-----|
| 概念 | `### 0. 解决的问题` (## 一、基础信息下) | `grep -c '### 0\. 解决的问题' 30_核心概念/*.md` |
| 知识点 | `### 0. 解决的问题` (## 一、基础信息层下) | `grep -c '### 0\. 解决的问题' 50_知识点/*.md` |

内容要求：1-2句话，含"解决{具体问题}。{价值说明}"格式。不能是套话模板。

### 7. 技能点内容聚焦实操，说明具体实施方法

| 检查项 | 位置 |
|:-----|:-----|
| 核心操作内容 | `### 1. 核心操作内容` — N步法描述 |
| 实操步骤 Mermaid | `### 2. 实操步骤` — 流程图 |
| 工具支撑 | `### 2. 工具支撑` — 具体仪器型号 |
| 典型实操案例 | `### 3. 典型实操案例` — 含诊断数据 |

### 8. 应用场景页面完整展示解题全流程

- 典型工作流程 Mermaid (完整 DAG)
- 案例操作流程说明 (阶段分解)
- 典型应用案例 (方案详解，含设计参数)
- 知识脉络图 + 解析
