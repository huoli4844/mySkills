# 教材质量核验脚本

对已生成的章节 .md 文件运行综合核验清单（13项 + 章级模式检查）。

用法：
```bash
# 对一章进行核验
python3 scripts/verify_chapter.py output/第1章-绪论.md

# 详细模式
python3 scripts/verify_chapter.py output/第1章-绪论.md --verbose

# 批量检查
python3 scripts/verify_chapter.py output/*.md
```

## 13 项核验清单

| # | 项 | 说明 |
|:-:|:---|:-----|
| 0a | 内容提要 | 章首有 `## 内容提要` |
| 0b | 学习目标 | 5-7 条以可验证动词开头 |
| 1 | 权威定义 | GB/T + IEC + IEEE + GJB 至少3标准并列 |
| 2 | 直观引入 | 第一段不是公式 |
| 3 | 公式编号 | `\tag{N-M}` 至少3个 |
| 4 | "式中"变量解释 | 紧跟公式后 |
| 5 | 数字实例 | "例 N-N" 格式至少1个 |
| 6a | 本章总结 | 章末5-7条要点 |
| 6b | 三层次习题 | 基础+进阶+思考 |
| 6c | 参考文献 | 标准格式，≥3条 |
| — | Mermaid说明 | 每个图有 `*图 X-X*` 文字说明 |
| — | LaTeX合法 | 花括号平衡 |
| — | 无KB泄漏 | 无"精准释义""本质特征"等模板字段 |

## 已知问题

- 本章总结计数使用 `^\d+\. ` 而非 `^\d+\. \*\*`，因为内联粗体行（如 `2. 任何...**三要素**`）不匹配后者。
