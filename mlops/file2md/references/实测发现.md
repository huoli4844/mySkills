# file2md 实测发现记录

> v2.1 更新：已改用 Docling 主引擎 + pandoc DOCX 引擎，以下为仍有效的发现。

## PDF 页眉页脚过滤

Docling 后处理已自动过滤 `·XX·` 格式的页码残留行和含页码的章节标题行。

## PDF 中公式的三种形态

| 形态 | docling能否提取 | 需要什么 |
|:----|:--------------:|:---------|
| **文本公式**（`G_t = 40dB` 等） | ✅ 转为 `$$ LaTeX $$` | Docling |
| **特殊字体公式**（Symbol/CMSL） | ⚠️ 部分 | MinerU |
| **图片公式**（渲染后嵌入PDF，本教材的主要问题） | ❌ 原样保留为图片 | MinerU 深度学习OCR |

## Pandoc 参数备忘

```bash
# macOS
brew install pandoc

# Linux
apt install pandoc
```

关键参数：
- `-t gfm+tex_math_dollars` — OMML 公式转 LaTeX
- `--wrap=none` — 不折行，保留原始段落
- `--columns=10000` — 防止宽表格被截断
- `--extract-media <dir>` — 提取嵌入图片
- `--markdown-headings=atx` — # 风格标题
