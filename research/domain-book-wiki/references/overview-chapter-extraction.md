# 概述/导引章概念抽取指南

## 问题

教材第1章（概述章）通常是对全书内容的总览和引子，非深入讲授。特点是：
- 段落短小，多数节段不足50行
- 覆盖面广但不深，每个主题点到为止
- 术语密集，大量定义性内容适合做KE
- 发展现状/历史回顾为叙述性内容，非教学概念

## 判断原则

### 不抽为概念的类型
| 类型 | 原因 | 去处 |
|:-----|:-----|:-----|
| 一句话定义 | 篇幅<50行，无展开 | KE |
| 发展现状/趋势 | 叙述性内容 | KE |
| 术语关系辨析 | 单词条短小 | KE |
| 纯列举分类 | 无展开讲解 | KE |

### 可抽为概念的类型
| 类型 | 特征 |
|:-----|:------|
| 贯穿全书的框架性概念 | 篇幅大、有子结构 |
| 有独立教学价值的主题 | 同一主题含多个子节 |
| 方法论/分类体系 | 有展开讲解和技术内容 |

## 处理流程

1. 用三标准对全章叶节点过滤
2. 框架性概念从**父容器**维度判定——父容器合并子节后满足标准可抽取
3. 概述章建议**3-5个概念**，不必追求数量
4. 其余短小定义性节段归入KE

## ⛔ 关键规则：KP/SP/Scene 不可跳过

概述章虽然概念数量少，但**仍需生成 KP（知识点）、SP（技能点）、Scene（应用场景）**：

- **KP**：从概念和KE中整合出结构化知识点（如"电磁兼容三要素分析法""电磁干扰源分类方法"）
- **SP**：从概念中的分析方法/操作流程提炼为技能点（如"电磁干扰三要素识别""快速判断干扰源类型"）
- **Scene**：将真实应用案例场景化（如"生产现场电磁干扰故障排查""电子设备出口EMC合规认证"）

**Agent 不得自行判断「概述章太浅，跳过 KP/SP/Scene」**。是否产生输出由 build 脚本决定（数据文件不存在则自然产生 0 文件），不由 Agent 预判。

## 第1章参考

当前合理概念集合：电磁兼容三要素、电磁干扰耦合途径、电磁兼容标准、干扰源分类。其余（电磁兼容定义、电磁环境、电磁干扰、发展现状、防护等）归入KE。
