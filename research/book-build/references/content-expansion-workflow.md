# 章节内容扩充工作流（2026-06-12）

## 背景

教材编写中，大纲定义了每节的目标体量（KB数），但 AI 初次生成往往远低于目标（如大纲目标300KB，实际仅60KB）。本参考文档记录经实战验证的扩充方法。

## 诊断方法

```bash
# Step 1: 对比大纲目标 vs 实际体量
#   写作大纲中有"建议体量"表格，例如：
#   8.1.1 静电屏蔽 25KB   → 实际仅 8KB → 缺 17KB
#   8.1.2 交变电场屏蔽 25KB → 实际仅 6KB → 缺 19KB
#
# Step 2: 检查大纲已定义但正文缺失的子节
#   如 6.3.3 混合接地/浮地、6.3.4 地平面与地栅系统等

# Step 3: 统计已有公式数，为 subagent 提供上下文
grep -c '\\\\tag{5-' 第5章-搭接技术.md   # 输出如 "69"
```

## delegate_task 指令模板

```python
{
    "goal": f"扩充第{ch}章内容至{X}KB以上",
    "context": f"""
文件：/path/to/第{ch}章-*.md（当前{N}KB）
写作大纲：/path/to/writing-guide-ch{ch}.md

大纲子节（标注缺失项）：
- 6.3.1 单点接地 ✅
- 6.3.2 多点接地 ✅
- 6.3.3 混合接地/浮地 ❌ 缺（需定量谐振频率计算）
- 6.3.4 地平面与地栅系统 ❌ 缺

已有公式数：{m}个（\\tag{{{ch}-1}}~\\tag{{{ch}-{m}}}）
补充时继续编号。
最后运行 batch_fix_formula_numbers.py。
"""
}
```

## 关键参数

| 参数 | 说明 |
|:----|:-----|
| 目标体量 | 写作大纲中"建议体量"列之和的当前比例（如目标400KB，当前80KB → 扩充至150KB为合理中间目标） |
| 公式连续性 | subagent 必须知道已有公式数量，用 `\\tag{ch-(已有数+1)}` 继续编号 |
| 并行限制 | max_concurrent_children=3，分两批执行 |
| 后处理 | 必须运行 `batch_fix_formula_numbers.py` 统一修复编号 |

## 常见问题

- **subagent timeout（600s）**：内容扩充任务耗时较长，600s限制可能不足。建议分多次委托，每次只扩充2-3节
- **patch 冲突**：subagent 可能对同一区域多次 patch，有时出现 "Found N matches" 错误。解决方案：增大 context 范围或用 write_file 替换
- **公式重复**：不同 subagent 可能使用相同的公式编号。解决方案：最后统一运行 batch_fix
