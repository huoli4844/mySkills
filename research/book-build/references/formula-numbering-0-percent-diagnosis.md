# 公式编号 0% 缺失 — 根因诊断记录（2026-06-11）

## 诊断过程

用户反馈：质量检验时公式编号被删除。实际生成的公式本应带编号。

### 验证步骤

1. **检查 post_generation_check.py 是否删除编号**：`check_formulas` 只报告不删除；`_fix_missing_tag` 只补缺不删除
2. **检查 renumber.py 是否误删**：Step 3 确实删除所有 `\\tag{}`，但 Step 4 会重新编号
3. **检查源文件是否含编号**：13 章 739 个公式，**0 个有 `\\tag{}`**

### 结论

根因在 **AI 写作阶段**，不在质量检查或重排脚本。

`gen_prompt.py` 第五节"段落与过渡"明确写了 `公式编号：\\tag{章-序号}`，但 AI Agent 在 `delegate_task` 写每节时系统性忽略此指令。

## 修复方案

```bash
# 对每章运行 renumber.py 自动补充编号
python3 scripts/renumber.py output/第N章-*.md
```

`renumber.py` 流程：
1. 备份原文件（.bak）
2. 修复孤立 `\\tag` 行
3. 转换单行 `$$inline$$` 为多行 block
4. 清除所有旧编号（如果存在）
5. 按出现顺序分配连续编号 N-1, N-2, ...
6. 写入修复结果

## 预防

在 `delegate_task` 写节的 context 中必须显式加入：

```
⚠️ 公式编号铁律：每个 $$...$$ 块内必须有 \tag{章-序号} 编号。
\tag{} 独占一行，放在 $$ 闭合之前。
没有编号的公式 = 不合格的输出。
```
