## 关键发现

1. **写作大纲质量决定章节正文质量**：大纲从 20KB→93KB 直接导致正文从 6 案例→10+案例、2 Mermaid→8 Mermaid。
2. **6选3勾选制有效**：5节正文全部使用6选3，选中最匹配的要素实现，无强制全素的机械感。
3. **内联示例消除§引用跳转**：开篇三法/概念四步法/设问过渡均可直接复制使用，无文件跳转。
4. **质量审计误报已修复**：中间推导步骤不再误报"缺编号"；exercises regex 已匹配 `**1.1**` 格式。
5. **python-docx 是必需依赖**：`init_project.py` 解析提纲 docx 需要 `python-docx`；未安装时仅骨架生成（占位符）。

## 附录：管线入口速查

```bash
# Phase 0: 领域注入
python3 scripts/domain_init.py --project /path/to/教材

# Phase 1: 项目初始化 + 大纲骨架 + QC + 任务（四合一）

python3 scripts/quality_audit.py --project /path/to/教材 --chapter 1
python3 scripts/post_generation_check.py output/第1章-绪论.md
```
