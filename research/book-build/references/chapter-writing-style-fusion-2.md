# 写作风格融合（续）

> 接上一部分 3.5-3.7



每节写完后，检查是否同时具备三种视角：

```
□ 【张亮】本节是否从读者能感知的现象出发？
   （不是从定义出发，而是从"你见过……吗"出发）
   
□ 【梁振光】本节是否有清晰的结构和完整的概念定义？
   （对比表、关系图、多标准并列、条件分解）

□ 【路宏敏】本节是否有足够的细节深度？
   （具体年份、数字、组织全称、技术参数、事件分析）
   针对不同内容类型的深度要求：

| 内容类型 | 路宏敏式深度要求 |
|:---------|:----------------|
| 案例描述 | 每个案例有具体时间、地点、数字原因、技术分析、教训提炼 |
| 历史事件 | 每段有组织全称、成立日期、具体技术参数、事件意义分析 |
| 概念定义 | 引用3-4个标准原文，提取共同核心，分解为条件 |
| 框架要素 | 给出数学模型+"式中"解释，用多场景验证表，附策略 |
| 研究内容 | 每项2-4段，包含原理说明+工程实例+前沿方向 |
```

### 3.6 具体示例：历史事件的路宏敏式深度要求

| 要写的内容 | 概括式写法（错误） | 路宏敏式写法（正确） |
|:----------|:-----------------|:-------------------|
| CISPR成立 | "1933年CISPR成立。" | "1933年，国际无线电干扰特别委员会（CISPR——Comité International Spécial des Perturbations Radioélectriques）在法国巴黎成立。CISPR的第一次会议于1934年6月28日至30日在巴黎召开。" |
| 欧共体EMC强制 | "1996年欧盟强制执行EMC指令。" | "1996年1月1日，欧洲共同体12个国家和欧洲自由贸易联盟的北欧6国共同宣布强制执行EMC指令（89/336/EEC），凡不符合EMC标准的产品一律不准进入欧盟市场。" |
| 中国首个EMC标准 | "1966年我国发布第一个EMC标准。" | "1966年，原第一机械工业部发布了我国第一个干扰标准JB 854—66《船用电气设备工业无线电干扰端子电压测量方法与允许值》。" |

**原则**：每条历史事件必须包含"年份 + 组织全称（含英文） + 具体日期（如可能） + 事件经过 + 事件意义（为什么重要）"五个要素，缺一不可。

### 3.7 张亮式核心技巧：从现象到概念 + 工程实用导向

这是从张亮《EMC技术及应用实例详解》中提炼的两项关键写作技巧，与路宏敏的详实性和梁振光的系统性并列，构成多教材融合的第三根支柱。

#### 3.7.1 技巧一：从现象到概念（每个概念必须从日常场景出发）

**核心规则**：在给出任何专业定义之前，先用读者一定经历过的日常电器现象"搭桥"。

**标准结构**：
```
第1句：描述一个或一组日常电器现象
  → "打开电视机时，旁边的日光灯管会瞬间变暗一下"
  → "使用吹风机时，收音机发出啪啦啪啦的噪声"
  → "手机靠近音箱时，音箱发出滋滋的刺耳声"
  （选择读者99%经历过的场景，用3-4个短现象平行列举）

第2句：点明这些现象的共同点
  → "这些看似互不相关的小麻烦，背后都是同一个工程问题"

第3句：引出专业术语
  → "这个现象在工程上有一个专门的名字——电磁干扰"
```

**示例**（取自改写后的第1章）：
```markdown
打开电视机时，旁边的日光灯管会瞬间变暗一下——这是因为大量电流涌向电视机，
同一电源线上的日光灯"抢"不到足够的电压。使用吹风机时，附近的收音机发出
"啪啦啪啦"的噪声——这是因为吹风机的电动机在运转时产生了微弱的脉冲电流，
通过电源线传入了收音机。手机靠近音箱时，音箱发出"滋滋"的刺耳声——
这是因为手机的射频信号通过空间传播到音箱电路。这些都是每一个人在日常生活中
都曾遇到过的小"麻烦"，但它们背后指向的是同一个工程问题——电磁干扰。
```

**适用场景**：
- ✅ 概念定义类（EMD/EMI/EMC定义）
- ✅  框架/要素类（三要素）
- ✅ 机理说明类（传导/辐射干扰）
- ❌ 历史叙事类（用路宏敏式详实叙事更合适）
- ❌ 研究内容综述类（用梁振光式系统结构更合适）

**可用的日常现象库**：
| 现象 | 说明的EMC概念 | 涉及的耦合类型 |
|:-----|:-------------|:-------------|
| 电视机→日光灯变暗 | 传导干扰 | 电源线传导（共电源阻抗耦合） |
| 吹风机→收音机杂音 | 传导干扰 | 电源线传导 |
| 手机→音箱滋滋声 | 电磁干扰（一般概念） | 空间辐射 |
| 手机→CRT屏幕抖动 | 辐射干扰 | 空间辐射 |
| 微波炉→WiFi变慢 | 辐射干扰、频段重合 | 空间辐射（同频干扰） |
| 汽车经过→收音机杂音 | 辐射干扰 | 空间辐射（点火噪声） |
| 电梯启动→屏幕闪烁 | 瞬态干扰 | 电源线传导 |
| 静电→触摸电脑重启 | ESD干扰 | 接触放电/空气放电 |

#### 3.7.2 技巧二：工程实用导向（每个研究内容/技术必须配"有什么用"）

**核心规则**：在介绍任何研究内容或技术原理之后，必须立即给出具体的工程应用场景，让读者知道"这东西在现实中是怎么用的"。

**标准结构**：
```
[原理说明]  →  1-2段解释技术原理

[工程场景]  →  1个具体的工程问题场景
  以"例如，在产品开发中……"或"以一个具体工程为例……"开头
  给出参数、数值、操作步骤等具体细节

[应对措施]  →  具体的技术措施或解决方案
  列出实际工程中采用的手段、方法或器件
  区分不同条件下的不同做法
```

**示例**（取自改写后的第1章1.3节——研究内容）：
```markdown
**⑤ 电磁兼容性测量和试验技术。** EMC测量贯穿于产品分析建模、开发设计、
检验认证、干扰诊断等各个阶段……研究内容包括：EMI测量和EMS测量两大部分。

EMI测量分为传导发射（CE）测量和辐射发射（RE）测量——CE测量通常使用
线路阻抗稳定网络（LISN）和EMI接收机在9kHz~30MHz频率范围内进行，RE测量
则在天线、电波暗室和EMI接收机的配合下在30MHz~1GHz频率范围内进行。

各种测量设施各有特点和适用条件：开阔试验场（OATS）具有最真实的电磁环境
但受天气和背景噪声影响大；半电波暗室和全电波暗室在受控环境条件下进行
EMC测量，是目前使用最广泛的设施；TEM小室和GTEM小室适用于较小尺寸设备
的测量；混响室适用于大尺寸设备的高场强测试。

EMI接收机不同于普通的频谱分析仪——它内置了准峰值检波器和标准规定的测量
带宽，能够按照CISPR 16等基础标准的要求进行合规性测量。
```

**每个研究内容必须配的工程要素**：
| 工程要素 | 说明 | 示例 |
|:---------|:-----|:------|
| 频率范围 | 给出具体数值 | 9kHz~30MHz、30MHz~1GHz |
| 技术参数 | 给出量化和比较 | ESD脉冲上升时间亚纳秒级、场强40kV/m |
| 使用设备 | 给出设备名称 | LISN、EMI接收机、CDN |
| 操作流程 | 给出步骤 | 幅度筛选→频率筛选→详细预测→性能分析 |
| 适用条件 | 区分不同条件 | OATS vs 电波暗室、近场 vs 远场 |
| 数学描述 | 给出算法/方程 | 双指数函数描述ESD、MoM/FDTD等数值算法 |

#### 3.7.3 完整的张亮式段落模板

```markdown
【开场】日常现象引入（技巧一）
  → 2-3个读者一定经历过的场景
  
【过渡】现象到概念的桥梁
  → "这些现象在工程上称为……"
  
【定义】梁振光式系统定义
  → 标准定义+多标准并列
  
【工程深化】路宏敏式详实展开 + 工程实用细节（技巧二）
  → 具体参数、设备名称、操作流程、适用条件
  
【收束】回到读者经验
  → "现在你知道为什么……了吧"
```

#### 3.7.4 多教材融合的质量检查清单（扩展版）

每节写完后，逐一确认：

```
□ 【张亮·现象锚定】本节是否以一个或多个日常电器现象开头？
   → 具体写了哪个现象：__________
   → 这个现象是否100%的读者都经历过？
   
□ 【张亮·工程实用】本节的技术内容是否配了工程场景？
   → 是否有具体的频率范围/技术参数？
   → 是否有设备名称/操作步骤？
   → 是否有不同条件下的区分说明？
   
□ 【梁振光】本节是否有清晰的结构和完整的概念定义？
   → 对比表/关系图/多标准并列/条件分解
   
□ 【路宏敏】本节是否有足够的细节深度？
   → 具体年份/数字/组织全称/技术参数/事件分析
```
