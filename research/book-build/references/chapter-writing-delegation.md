# 章节写作委托指南（Chapter Writing Delegation Guide）

> 实践经验：一次完整章节委托约需 400~500 秒、50~130 万输入 token、1~4 万输出 token。

## 委托 prompt 必含项

委托子 Agent 写章节正文时，必须在 context 中明确以下内容：

### 1. 公式格式（硬性约束）
- **禁止使用 `\[ ... \]`** LaTeX 显示数学语法
- **必须使用 `$$ ... $$`** Markdown 块级公式
- `\tag{N-M}` 独占一行，放在 `$$` 闭合前
- 违反此约束 → `post_generation_check.py` 会报 "tag 在 $$ 块外部" 错误

### 2. Mermaid 铁律
- 仅 `graph LR`（横向优先）
- 禁止 `timeline` / `mindmap` / `subgraph` / `%%{init}%%` / emoji
- 节点标签用双引号：`A["标签文字"]`
- 换行用 `<br>` 不用 `\n`
- 白底黑字，不设任何主题

### 3. 案例要求
- 必须来自公开报道真实事件
- 格式：公司名 + 时间 + 具体技术参数（频率/电压/距离/金额等）
- 每节 ≥ 2 个案例（1 生活化 + 1 工程）
- 禁止从参考教材（路宏敏/张亮/梁振光/柯金良）摘抄案例
- 推荐来源：丰田、特斯拉、波音、苹果、SpaceX、华为、深圳地铁等

### 4. 正文结构
- 首次出现的术语**加粗 + 英文全称**
- 核心公式需 4 步推导（物理原理→建模假设→数学代入→导出结果→参数解释）
- 每节 ≥ 2000 字
- 每节至少 1 个 Mermaid 图/表格
- 章末包含：本章总结（Mermaid 图 + 6 核心要点表）+ 习题（8~12 题）+ 参考文献（≥10 篇）+ 深入阅读（3~5 本）

### 5. 禁止项
- 禁止 `[[wikilink]]`
- 禁止 Bloom 分类标签
- 禁止 `[待补充]`/`[TODO]` 占位符
- 禁止引用格式错误的 `\tag{...}`（缺少 `{` 或多余空格）

## 常见问题

| 问题 | 表现 | 解决办法 |
|:-----|:-----|:---------|
| `\[ \]` 代替 `$$` | post_generation_check 报 tag 在 $$ 外 | context 中明确禁止 `\[ \]` |
| 案例从教材摘抄 | 质量审计通过但无真实企业名 | context 中指定"禁止从参考教材摘抄" |
| 缺 Mermaid 图注 | 审计报 WARN | 在写图后的 3 行内加 `*图N-X 标题*` |
| 公式缺推导 | 推导深度检查不通过 | 要求"公式前有推导词（由/根据/代入）" |
| 多节共用同一案例 | 读者感重复 | 要求每节用不同配型的案例 |
