# KB 数据质量规则

> 本文件被 `kb-qa` 技能引用，定义了 kb-qa 在问答、补齐、纠错过程中需要遵循的质量规则。
> 来源：2026-05-19-20 会话中用户的偏好积累 + emc-textbook-wiki 长期规则

## 置信度规则（任何自动补齐/纠错必须遵守）

| 场景 | confidence | verified | source | 说明 |
|:-----|:-----------|:---------|:-------|:-----|
| 问答自动补齐概念 | 0.65 | false | kbqa-v3-complete | 自主生成，非出处原文 |
| 问答自动补齐KE | 0.65 | false | kbqa-v3-complete | 自主生成 |
| 问答自动补齐KP | 0.65 | false | kbqa-v3-complete | 自主生成，简版模板 |
| 用户纠错后重新生成 | 0.65 | false | kbqa-v3-corrected | 用户修改，但无出处验证 |
| 用户提供出处原文后升级 | 0.95 | true | emc-textbook-wiki Step 4-5 | 出处验证通过 |
| 验证失败降级 | 0.65 | false | 保留原 source | 不允许删除，不允许保持0.95 |

## 自动补齐的页面模板规范

### 概念页（5层，无内容填"无"）

自动补齐概念必须包含全部 5 层：

```
## 一、基础层
### 1. 术语名称
### 2. 精准释义
### 3. 本质特征

## 二、解析层
### 1. 构成要素/原理
### 2. 分类
### 3. 边界条件

## 三、应用层
### 1. 应用场景/领域
### 2. 价值/作用

## 四、关联层

## 五、补充层
```

### 知识要素页（3层）

```
## 一、定义
## 二、核心内容
## 三、关联信息
```

### 知识点页（4层，简版）

```
## 一、基础信息层
### 1. 知识点名称
## 二、核心内容层
### 1. 理论基础
## 三、应用延伸层
## 四、关联知识层
### 1. 关联概念
### 6. 关联目录
```

## 链式补齐规则

创建概念/A 时，检查以下链式缺失：

| 概念 | 配套 KE | 配套 KP |
|:-----|:--------|:--------|
| 鉴相器 | 鉴相器输出公式 | 鉴相技术 |
| 干涉仪 | 干涉仪相位差公式, 干涉仪无模糊条件 | 干涉仪测向技术 |
| 时差定位 | 时差定位双曲线方程 | 时差定位技术 |
| 测向交叉定位 | 测向交叉定位矩阵公式 | 测向交叉定位技术 |
| 虚拟基线 | 虚拟基线公式 | — |
| 圆概率误差 | 圆概率误差(CEP)公式 | — |
| 几何稀释精度 | 几何稀释精度(GDOP)公式 | — |
