
这是从路宏敏、梁振光、张亮三本已出版教材中提炼的融合写作方法论。每节写作时必须同时运用三种视角。

### 3.1 三本教材的核心优势

| 教材 | 风格定位 | 核心优势 | 适用的内容类型 |
|:-----|:---------|:---------|:-------------|
| **路宏敏** (详实型) | 案例驱动，学术叙事 | 极致的细节密度——每个事件都有具体年份、数字、组织全称、技术分析。长段落自然流畅。 | 历史叙事、案例描述、技术分析 |
| **梁振光** (系统型) | 结构清晰，体系完整 | 清晰的章节组织——每节有明确主题，从概念到历史到内容到特点递进。内容提要+结构导览。 | 概念定义、内容综述、体系构建 |
| **张亮** (实例型) | 问题导向，贴近读者 | 从日常电器现象入手——电视机+荧光灯、手机+CRT、吹风机+收音机。先讲现象再讲原理。 | 概念引入、机理说明、工程分类 |

### 3.2 融合写作模式：各教材视角逐层递进

每节写作时，按以下顺序依次运用三本书的视角：

```
第1层：【张亮视角】——用日常现象建立认知锚点
  → 不允许直接给定义。先问"你见过……吗？"
  → 从电视机+日光灯、手机+音箱、微波炉+WiFi等日常配对入手
  → 例子：路宏敏的第1章从13个案例开始，不是从定义开始
  
第2层：【梁振光视角】——给出系统的概念和定义
  → 在读者有了感性认识后，给出标准定义
  → 用清晰的结构分解概念的各要素
  → 配对比表或关系图
  → 例子：梁振光的内容提要+系统结构使读者知道"现在在讲什么"

第3层：【路宏敏视角】——用极致细节深化理解
  → 在概念建立后，给出详实的工程案例
  → 每个案例有具体的时间、地点、数字、技术分析
  → 案例不是"讲故事"，而是"做分析"
  → 每个历史事件附上组织全称、具体日期、技术参数
```

### 3.3 各内容类型的多教材融合模板

#### 3.3.1 概念定义类（如EMD/EMI/EMC定义）

```
【张亮部分】从日常现象引入
  以"打开电视机时荧光灯变暗"或"手机靠近音箱滋滋响"开头
  点明"这就是电磁干扰"
  建立读者第一印象

【梁振光部分】系统定义+结构分解
  给出标准定义（GB/T、IEC、IEEE多标准并列）
  用对比表或关系表分解概念要素
  提取共同核心（两个条件：抗扰度+发射限制）

【路宏敏部分】详实案例深化
  给出2-3个工程技术案例（含具体数字）
  每个案例后做技术分析
  用"这一案例说明……"提炼教训
```

#### 3.3.2 框架/要素类（如三要素）

```
【张亮部分】从现象提炼框架
  "刚才的手机+音箱例子中，手机是____，音箱是____，空间是____"
  自然地引出三要素，不需要生硬过渡

【梁振光部分】系统阐述
  逐一列出各要素并详细解释
  给出数学模型S(f)·C(f)·C(f)≥R_th(f)
  "式中"解释每个符号

【路宏敏部分】工程验证
  用多场景分析表展示框架的实用性
  每个场景有具体的工程背景
  附上对应的EMC设计策略
```

#### 3.3.3 历史叙事类（如EMC发展史）

```
【张亮部分】先问"为什么要了解历史"
  用1-2句话说明历史的价值
  然后进入叙事

【路宏敏部分】极致的细节叙事（核心）
  每段历史必须有：具体年份、组织全称、关键人物、技术参数、事件意义
  分阶段时每阶段标出起止年份
  关键节点加一句"为什么这个事件重要"的分析

示例（路宏敏的写法）：
  "1933年，国际无线电干扰特别委员会（CISPR——Comité International Spécial
   des Perturbations Radioélectriques）在法国巴黎成立。CISPR的第一次会议
   于1934年6月28日至30日在巴黎召开。"
  而不是：
  "1933年CISPR成立。"（这才是典型的"概括式"写法——错误）

【梁振光部分】对照表收束
  用国际/国内对照表整理时间线
  每个条目包含年代、国际事件、中国事件
```

#### 3.3.4 内容综述类（如研究内容）

```
【梁振光部分】先区分狭义和广义
  给出整体框架，让读者知道"地图上有哪些区域"
  用编号或Mermaid图总览

【路宏敏部分】逐项详述
  每一项2-4段，每段有具体的技术内容
  不是简单列举，而是解释"为什么重要"

【张亮部分】穿插工程实例
  每项内容配1-2个具体工程场景
  让读者看到每项研究内容的"用处"
```

### 3.4 实例对比：同一概念的三种写法

以"电磁干扰"这个概念为例，展示三本书的不同写法：

**张亮的写法（从现象到概念）**：
```
打开电视机时，室内的日光灯会出现瞬间变暗的现象，这是因为大量电流流向
电视机，电压骤然下降，利用同一电源的日光灯受到影响。还有使用吹风机时
收音机会出现"啪啦，啪啦"的噪声。原因是通过电源线传递而进入收音机，
以噪声的形式表现出来。像上面这种由一个设备中产生的电压/电流通过电源线、
信号线传导并影响其他设备时，将这个电压/电流的变化称为"传导干扰"。
```
特点：从日常现象出发，读者立刻有代入感，然后自然引出专业术语。

**路宏敏的写法（案例驱动，详实叙实）**：
```
1969年11月14日上午11时22分，由美国土星V火箭运载的"阿波罗"12号宇宙
飞船竖立在肯尼迪试验场的第39号发射架上准备发射。当时发射场的天气情况是：
在距地面240~250m及650~33000m之间有两层云，发射周围细雨绵绵……当计时
秒针走到第36.5秒、火箭飞行高度达到1920m时，从云层到火箭直到地面之间
发生了雷电现象……
```
特点：不是从"定义"开始，而是从"故事"开始。读者在阅读案例的过程中自然
建立了对EMC重要性的认知，后续的定义变成了"理所当然"。

**梁振光的写法（系统定义，清晰结构）**：
```
电磁兼容有两层含义：对于设备或系统的性能指标来说，是指"电磁兼容性"；
作为一门学科来说，则为"电磁兼容（学）"。电磁兼容及电磁干扰抑制技术
是随着无线电广播、通信技术的发展而逐步成长起来的。
```
特点：先给出清晰的定义框架，然后用结构化的方式展开。

**多教材融合写法的效果**：
```
第1段（张亮风格）：一个人打开电视机时，旁边的荧光灯管闪了一下；用吹风机
时收音机发出"啪啦"声；手机靠近CRT屏幕时图像开始抖动——这些日常经历
背后，都是同一个工程问题：电磁干扰。

第2段（梁振光风格）：电磁干扰（Electromagnetic Interference，EMI）是
指电磁骚扰引起的设备、传输通道或系统性能的下降。它与电磁骚扰
（Electromagnetic Disturbance，EMD）有着本质区别：骚扰是原因，干扰是
后果。两者关系可表示为……（下接定义、对比表）

第3段（路宏敏风格）：1969年11月14日，"阿波罗"12号飞船升空36.5秒时，
两道闪电击中了火箭，飞船的电源系统被破坏、导航系统失效、飞行平台失控。
事后分析表明，火箭及其火焰形成的导电体（总长约300m）人为诱发了雷电。
这一案例揭示了一个重要教训：在强电场环境下，大型导体可能成为雷电的"触媒"。
……
```
这样，读者的认知过程是：
  日常经验（张亮）→ 概念建立（梁振光）→ 深度案例（路宏敏）→ 真正理解
