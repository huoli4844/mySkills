# 链式补齐规则表

在 kb-qa Phase C→D 的审阅补齐过程中，创建某类型节点时自动检查配套节点类型是否也存在。本文件记录已验证的规则映射。

## 规则类型

| 源节点类型 | 目标节点类型 | 命名模式 | 说明 |
|:-----------|:-------------|:---------|:-----|
| 概念 | 知识要素 | `概念/{名称}` → `知识要素/{名称}公式/规则` | 核心概念配套的公式/方法/规则 |
| 概念 | 知识点 | `概念/{名称}` → `知识点/{名称}技术` | 概念的完整技术专题 |
| 知识要素（公式） | 概念 | `知识要素/{名称}公式` → `概念/{名称}` | 公式基于的核心概念 |
| 知识点 | 概念 | `知识点/{名称}技术` → `概念/{名称}` | 知识点的核心概念基础 |

## 规则扩展方法

当知识库中检测到新的概念→KE→KP 关系时：

1. 在问答中创建新概念页时，手动检查 KB 中是否存在配套的 KE/KP
2. 若发现新的映射关系，追加到本文件
3. 链式数量超过 30 条时，考虑分表（按章节或领域）

## 通用匹配启发式（无精确规则时的回退）

若 KB 中无精确规则，使用以下启发式：

```
概念/{名称}
  → 检查 知识要素/{名称}\w* 是否存在（LIKE 匹配）
  → 检查 知识点/{名称}\w* 是否存在（LIKE 匹配）

KE/{名称}
  → 检查 概念/{名称去掉"公式"/"规则"/"条件"} 是否存在

KP/{名称}
  → 提取 KP 名称中的核心术语，检查 概念/{术语} 是否存在
```

## 注意事项

- 链式创建的所有页面标记 `confidence: 0.65`, `source: "kbqa-v3-complete"`, `verified: false`
- KE 可能已存在于 KB 但置信度值为 0.75/0.85（与用户规则 0.65 不一致）——这是 KB 构建早期的遗留问题，不应修改已有 KE 的置信度，仅确保新建页面使用正确值
- 创建概念页后，务必 update 已有相关概念页的关联层追加 wikilink（双向链接卫生）
