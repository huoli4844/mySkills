## 教学链（不可逆单向递进）

```
教材源文 → 核心概念(+KE+实体) → 知识点 → 技能点 → 应用场景
         ↑___原子知识__________↑  ↑__整合层__↑  ↑___顶点___↑
```

## Bloom 值域（v43.7 代码校验）

| 类型 | 允许值 | 典型值 |
|:-----|:------|:------|
| KP | 知道→理解, 知道→应用, 理解→应用 | 理解→应用 |
| SP | 应用, 理解→应用, 应用→分析, 分析 | 应用→分析 |
| Scene | 分析→评价, 分析→评价→创造, 评价→创造 | 分析→评价→创造 |

## 数据源——三标准过滤

教材 → 容器扫描(preprocess_toc.py) → 三标准过滤:

| 标准 | 阈值 | 检测方式 |
|:-----|:-----|:--------|
| 篇幅 | ≥50行 | `span_lines`（preprocess_toc.py 自动统计） |
| 支撑 | ≥3个 | `support_count`（公式+图+表合计，自动统计） |
| 结构 | 有展开 | Agent 语义判断（子标题/多段落） |

- 全部满足 → **核心概念** (confidence=0.95)
- 不满足 → **降级**: 定理/公式 → KE (0.85)，设备/组织 → Entity (0.85)

## 关键区别

| 对比 | 关键差异 |
|:-----|:--------|
| 概念 vs KE | 概念≥50行+≥3支撑+有结构；KE 是不满足三标准的降级品 |
| 概念 vs 实体 | 概念是抽象理论；实体是具象存在物（IEC/FCC/铁氧体磁环） |
| KP vs SP | KP 回答"是什么/怎么分类"；SP 回答"怎么做/步骤是什么" |
| SP vs Scene | SP 是单一技能操作；Scene 是多知识综合解决真实问题 |
| L2 vs L3 | L2 单书内统计；L3 跨书对比+冲突检测 |
