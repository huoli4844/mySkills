### 5.2 教材学术叙事风格（Real Textbook Writing Style）

> 🔑 **来自会话教训**：之前尝试了"六步教学法"(Step 1经验锚定→Step 6自检巩固)的写法，被用户判为"越写越差"——因为真实出版教材**从不使用显性教学步骤标记**。正确做法：研读已出版教材（如路宏敏、梁振光、张亮三本电磁兼容教材），学习它们的**学术叙事风格**，而非自创教学框架。

**三本参考教材的风格分析**：

| 教材 | 风格定位 | 开篇方式 | 段落特征 | 人称 |
|:-----|:---------|:---------|:---------|:-----|
| **路宏敏**《工程电磁兼容》 | 详实学术型 | 案例驱动，像讲故事 | 信息密集长段落 | 第三人称"人们" |
| **梁振光**《电磁兼容原理技术及应用》 | 系统讲授型 | 内容提要+直接进入主题 | 中段为主，结构清晰 | "读者"视角 |
| **张亮**《EMC技术及应用实例详解》 | 工程实例型 | 从日常电器现象入手 | 描述通俗，由浅入深 | "我们" |

**三本教材的共同特征（必须遵循）**：

| 维度 | 正确做法 | ❌ 常见错误（会触发用户强烈不满） |
|:-----|:---------|:----------------------------------|
| **叙事风格** | 第三人称客观学术叙述（"人们""读者""我们"） | 第二人称"你"对话式（"你有没有过这样的经历"） |
| **段落** | 信息密集型长段落，一段讲清楚多个层次 | 刻意拆成极短段落，一句一行 |
| **定义处理** | 定义融入自然叙述当中，不设独立"定义框" | 单独划出一个"定义"子节，像维基百科条目 |
| **教学步骤** | 靠信息密度和自然过渡来"教"，没有显性标记 | "Step 1: 经验锚定""自检巩固："等标签（用户说"你越写越差了"） |
| **自检** | 通过章末习题完成，不内嵌 | 在每个概念末尾嵌"请你自己判断……" |
| **结构** | "大纲即法律"——标题与大纲逐字匹配 | 自行修改标题、增减章节 |
| **案例** | 详细叙述经过后自然带出分析 | 用"EMC启示："等显性标记隔开 |

#### 5.2.1 正确写法 vs 错误写法对比

**定义处理**：

```markdown
❌ 错误写法（显性教学标签+第二人称）：
"你有没有过这样的经历？手机靠近音箱，音箱发出滋滋声。
这个现象叫电磁干扰。
电磁干扰是指电磁骚扰引起的设备性能下降。"

✅ 正确写法（第三人称学术叙事，定义融入段落）：
"电磁干扰是与电气、电子设备相伴而生的。设备在正常工作时，
往往会产生一些有用或无用的电磁能量，这些电磁能量可能影响
处于同一电磁环境中的其他设备或系统。在深入讨论电磁兼容之前，
必须首先厘清两个密切相关但本质不同的概念——电磁骚扰（EMD）
和电磁干扰（EMI）。"
```

**段落长度**：

```markdown
❌ 错误写法（刻意拆短，一句一段）：
"电磁干扰是指电磁骚扰引起的设备性能下降。
它强调的是后果。
EMD强调的是可能性。
EMI强调的是实际后果。"

✅ 正确写法（信息密集型长段）：
"电磁干扰是指电磁骚扰引起的设备、传输通道或系统性能的下降。
我国国家军用标准GJB 72A—2002对电磁干扰的定义更加直接：
任何能中断、阻碍、降低或限制通信电子设备有效性能的电磁能量。
干扰（Interference）一词强调的是'实际后果'——性能下降已经发生。"
```

#### 5.2.2 第二人称"你"的使用红线

**绝对禁止将"你"用于说明性/教学性文字**——这是"辅导班讲义"和"正式教材"的分水岭。

| 使用情景 | 允许？ | 示例 |
|:---------|:------:|:------|
| 章首内容提要 | ❌ 用"读者"替代 | "使读者对……有总体了解" |
| 正文论述 | ❌ | "电磁干扰是指……"（客观陈述） |
| 定义解释 | ❌ | "这种因果关系的理解是学习……的逻辑起点" |
| 过渡句 | ❌ 用"我们"替代 | "在讨论了基本概念之后，下面来回顾发展历程" |
| 习题题干 | ✅ | "回顾你日常使用的电子设备……" |

#### 5.2.3 段落写作准则

- **信息密集**：一段承载2-3个信息层次，不一句一换行
- **自然长度**：核心论述100-300字，过渡30-80字，不人为控制等长
- **逻辑内嵌**：因果、转折、递进关系在段落内部通过关联词完成，不另起段
- **首句定调**：段落首句是"主题句"，点明本段核心论点
- **引证融入**：引用标注放在句末【路宏敏，§1.2】，不影响行文流畅

## 六、写作后验证清单

每章写完后，必须逐项验证以下四个维度：

### 6.1 大纲结构验证

```python
outline_checks = [
    '## N.1 标题', '### N.1.1 标题', '（1）xxx', '（2）yyy',
    '### N.1.2 标题',
    '### N.1.3 标题', '（1）xxx', '（2）yyy', '（3）zzz',
    '## N.2 标题', '### N.2.1 标题', '### N.2.2 标题',
    '## N.3 标题',
    '## N.4 标题',
    '## 本章总结', '## 习题', '## 参考文献', '## 深入阅读',
]
# 所有check必须全部True
```

### 6.2 学习目标可答性验证

每条目标拆解为3-5个具体知识点，逐一检查正文中是否覆盖：

```python
learning_objectives = {
    '目标1': ['关键词A', '关键词B', '关键词C'],
    '目标2': ['定义A', '定义B', '区别描述', '关系表'],
    # ...
}
# 每个关键词在正文中出现 → 可答
```

### 6.3 深度验证

```python
depth_checks = [
    ('每节段落数', '≥3段/节'),
    ('概念节实例数', '≥1个实例/节'),
    ('公式后"式中"', '≥1次/公式'),
    ('对比表维度', '≥5维/表'),
    ('习题覆盖学习目标', '≥6/7条目标被覆盖'),

### 6.4 完整性验证

```
□ 内容提要（章首）
□ 学习目标（章首，7条）
□ 大纲所有节已写，无遗漏无多出
□ 每节遵循 5层递进（直观→定义→分解→实例→收束）
□ 本章总结（章末，6条）
□ 三层次习题（基础+进阶+思考，≥10题）
□ 每道题标注学习目标和节号
□ 参考文献（标准格式，≥3条）
□ 深入阅读（可选，≥2本）
□ 各处"详见第X章"后向预告（第1章≥3处；其他章≥2处）
```

## 八、已验证的章节写作模式（从实战中提炼）

### 8.1 "从路到场"渐进式耦合分析模式（第4章验证有效）

适用于电磁耦合/能量传输类章节。教学结构按照"电路级→分布参数级→场级"的认知顺序递进。

**第一层：电路模型（KVL/KCL基础）** — 从基尔霍夫定律出发。共阻抗耦合 $U_2 = U_1 Z_{12}/(Z_1+Z_{12})$ 直接来自KVL分压公式。电容性耦合从KCL相量模型导出。电感性耦合从法拉第定律导出。目标是让读者用已学的电路知识理解耦合的物理本质。

**第二层：频域扩展（频率特性分析）** — 引入频率变量。电容性耦合 $U_2 = j\omega C_{12}R / [1 + j\omega R(C_{12}+C_{2G})] \cdot U_1$ 是一阶高通特性，推导转折频率 $f_c$ 和低频/高频近似。让读者理解"低频耦合弱、高频耦合强"的分段规律。

**第三层：分布参数与过渡（传输线效应）** — 当导线电长度超过0.1λ时（对应>30 MHz），集总参数模型失效。引入传输线效应、反射、驻波。30 MHz是EMC测量中传导发射和辐射发射的分界频率——让读者理解为什么这个频点是分界。

**第四层：场理论（近远场+波阻抗）** — 从电基本振子场方程的三项推导近区（$1/r^3$）和远区（$1/r$）划分。波阻抗 $Z_w = \sqrt{\mu_0/\epsilon_0} \approx 377\Omega$。

**层次衔接**：电路(KVL) → 频域(一阶高通) → 传输线(分布参数) → 场(麦克斯韦)。用频率升高作为贯穿各层的驱动轴。**不违反原则**：不在第一层引入麦克斯韦，也不止步于电路级。
```
