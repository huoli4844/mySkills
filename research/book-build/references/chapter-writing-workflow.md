# 每章写作前：三书研读与写作指南生成工作流

## 核心理念

**不读三书不落笔。** 每一章动手写之前，必须先到三本教材的知识库目录下阅读对应的章节原文，分析三本书的写作手法，形成该章的**写作指南文件**，然后严格按照指南动笔。

## 为什么要这样做？

| 原因 | 说明 |
|:-----|:------|
| 吸收真正的教材感 | 三本书是已出版的正规教材，它们的段落节奏、公式融入方式、案例写法是经过编辑审定的 |
| 避免千篇一律 | 每章内容不同，三本书的写法也不同。第2章和第5章的分析结果完全不同 |
| 获取领域真实素材 | 三本书中有大量具体的工程数据、历史事件、标准号，这些是通用知识库无法替代的 |
| 避免自我重复 | 不参照原文，Agent 容易每章用同一模板重复写作 |

## 工作流：四步法

```
Step 1: 源文研读
  → 找到三本书该章对应的 .md 文件
  → 逐本通读全文（至少前30%和核心节的全部）
  → 记录：每本书用了什么手法、有什么亮点、有什么独特数据

Step 2: 手法分析
  → 填写三书写作手法对比表
  → 标注每本书在该章中最值得借鉴的3-5个手法
  → 标注三本书在该章中都有但没有写透的内容（我们的发挥空间）

Step 3: 生成写作指南
  → 基于分析结果，输出该章专用的写作指南文件
  → 包含：结构建议、每节深度指南、要引用的路宏敏数据/张亮案例/梁振光分类

Step 4: 按指南写作
  → 将写作指南作为子 Agent 或自己的写作指令
  → 写作过程中随时回看指南，确保每节按指南展开
```

### 1.2 读什么

**每本书重点读三部分：**

| 部分 | 为什么要读 |
|:-----|:-----------|
| **章首部分（前2-3节）** | 看每本书如何开门见山、如何引出主题、如何定义概念 |
| **中间核心节（深度技术节）** | 看细节深度——公式如何融入、案例如何展开、表格如何使用 |
| **章末部分（总结+习题）** | 看每本书如何收尾、习题的层次分布 |

### 1.3 读的时候注意什么

每个段落问自己三个问题：

1. **"这段在教什么？"** — 识别写作意图（定义/举例/推导/对比/总结）
2. **"为什么这样写？"** — 分析手法选择（为什么用表格而不是文字？为什么先现象后定义？）
3. **"这里有什么独特数据？"** — 提取亮点数据（时间/地点/标准号/具体数值/历史事件全称）

## Step 4: 按指南写作

### 4.1 写作过程中的对照

写作过程中随时回看写作指南：

```markdown
写作前：
  □ 已通读三书对应章节
  □ 已完成三书手法对比表
  □ 已标注三书共同盲区
  □ 写作指南文件已生成

写作中：
  □ 每写一节前再看该节的指南
  □ 每写完一节检查是否符合分配的素材和手法
  □ 每写完一节检查设问过渡是否到位

写作后：
  □ 对照写作指南逐项检查（不遗漏任何要素）
  □ 检查总字数是否达到该章目标
  □ 检查12条军规是否全部落实
```

### 4.2 写作中再回看原文

如果写作过程中遇到某知识点不知道怎么展开：

```bash
# 打开对应书本的对应节，看路宏敏/梁振光/张亮是怎么写这个点的
read_file /path/to/路宏敏/第N章.md --offset {行号} --limit 50
read_file /path/to/梁振光/第N章.md --offset {行号} --limit 50
read_file /path/to/张亮/第N章.md --offset {行号} --limit 50
```

不要凭感觉编造，要基于真实教材的写法去扩展。

## 第2章示例（三书研读结果）

### 路宏敏第2章（电磁兼容基本概念）

路宏敏第2章的核心内容是：电磁干扰三要素、电磁兼容基本概念、电磁兼容研究领域、电磁兼容发展史、电磁兼容特点。

**章首手法**：直接给出EMC定义（国家标准GB/T 4365-2003），然后展开三要素。

**核心特点**：
- 发展史写得极详细：CISPR 1933年启动、第一届1934年6月28-30日巴黎召开、6个国际组织+具体日期+事件意义
- 案例丰富：每个概念配案例，如飞机静电放电、核电磁脉冲、手机与显示器
- 数据极致：中国标准发布时间到年、各国标准机构全称含英文

**独特素材**：
- CISPR 1933年成立→1934年6月28-30日首次会议→1967年提出国际无线电干扰标准
- FCC 1979年对数字设备辐射管制→1990年扩展到商用设备
- 路宏敏13个案例的具体数据（具体到dB数值）
- 中国EMC标准体系的完整版本号（如GB/T 4365-1995）
- 国际国内EMC发展对照表

### 梁振光第2章（电磁兼容基本原理）

梁振光第2章的核心内容是：电磁兼容基本概念、电磁干扰三要素、电磁干扰分类、电磁兼容的研究领域、标准体系、电磁兼容展望。

**章首手法**：
- 内容提要（章导引）→ 开篇叙述 → 2.1 电磁兼容基本概念与解释
- 首先给三个国际定义（IEC/国家标准/个人解释）

**核心特点**：
- 概念定义系统清晰：EMC→EMI→EMS 逐步拆解，有对比说明
- 三要素公式化：S(f)·C(f)·R(f) 数学积模型
- 结构系统：电磁骚扰分类清晰（按属性/按耦合方式/按辐射时间等）
- 对比表丰富：EMI种类、标准层次结构、EMC与非EMC对比等

**独特素材**：
- 三要素的数学积模型：E(f)=S(f)·C(f)·R(f)（有编号公式）
- 电磁骚扰7种分类维度（按属性/按耦合方式/按辐射时间/按频带宽度/按频率范围/按波形/按受影响设备）
- 标准体系三层结构（基础/通用/产品类）
- 军用标准GJB的完整引用

### 张亮第2章（各试验项目详解）

**注意**：张亮第2章与本教材第2章主题不同。张亮第2章是试验项目的详细说明（ESD/RS/EFT/Surge等），不是EMC概述内容。因此张亮第2章对本教材第2章的参考价值有限，主要参考其**案例写法**和**工程实用导向**。

**可借鉴的写作手法**：
- 每个试验项目有"现象→定义→标准→工程措施"的完整链条
- 大量工程实际场景："例如，某工业现场..."

## 整个工作流的执行入口

每次写新章之前，执行以下命令：

```bash
# 1. 创建该章的写作指南文件
touch output/writing-guide-ch{N}.md

# 2. 加载三本书对应章节（先看大小，再通读）
wc -c /path/to/路宏敏/第N章*.md
wc -c /path/to/梁振光/第N章*.md
wc -c /path/to/张亮/第N章*.md

# 3. 浏览章首（前200行）
read_file /path/to/路宏敏/第N章*.md --limit 200
read_file /path/to/梁振光/第N章*.md --limit 200
read_file /path/to/张亮/第N章*.md --limit 200

# 4. 浏览核心节（从中间行开始）
read_file /path/to/路宏敏/第N章*.md --offset {行号} --limit 200

# 5. 浏览章末（最后200行）
read_file /path/to/路宏敏/第N章*.md --offset {总行数-200} --limit 200

# 6. 生成写作指南文件
# → 手动完成 Step 1-3 的分析 → 写入 output/writing-guide-ch{N}.md
```
