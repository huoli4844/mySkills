# 核心概念命名规范

## 规则

核心概念的 `name` 字段必须为**名词性短语**，不得使用动词短语、描述性章节标题或含标点符号的文本。

## 示例

### ✅ 正确（名词+分类词）

| 名称 | 结构 |
|:-----|:-----|
| 远场天线模型 | 定语 + 名词 + 模型 |
| 基波发射模型 | 定语 + 名词 + 模型 |
| 多导体传输线BLT方程 | 定语 + 专有名词 + 方程 |
| 电磁兼容三要素 | 领域 + 数量 + 要素 |
| 电磁干扰耦合途径 | 领域 + 名词 + 途径 |
| 数字电路无意发射 | 定语 + 名词 |
| 无意外天线辐射模型 | 定语 + 名词 + 模型 |
| 电场屏蔽 | 定语 + 名词 |
| 磁场屏蔽 | 定语 + 名词 |
| 反射滤波器 | 定语 + 名词 |
| 电源线滤波器 | 定语 + 名词 |

### ❌ 错误（动词句/标点句/描述句）

| 错误名称 | 问题 | 建议修改 |
|:---------|:-----|:---------|
| 数字电路**产生的**无意发射 | 动词"产生的" | 数字电路无意发射 |
| **"无意天线"的**辐射 | 引号+的 | 无意天线辐射模型 |
| **求解**多导体传输线的BLT方程 | 动词"求解"开头 | 多导体传输线BLT方程 |
| 金属平板屏蔽效能**的计算** | 的+动词 | 金属平板屏蔽效能计算 |
| 非实心型屏蔽体屏效**计算** | 动词作名 | 非实心屏蔽体屏效计算 |
| **关于**电磁屏蔽的几点思考 | 介词开头 | 电磁屏蔽 |

## 处理原则

1. 源文 `###` 标题是概念名的**来源**但不是**最终名称**——Agent 需判断该标题是否为名词性
2. 若明显是动词句（含"产生的""求解的""关于"等），需**简化为名词性**再写入
3. 含引号、标点符号的名称需清理（`"无意天线"` → `无意天线`，`"的"` 需判断是否保留）
4. `file` 字段与 `name` 保持严格一致
5. 改名后需同步更新所有章节的 wikilink（concepts.yaml / kps.yaml / sps.yaml / scenes.yaml / kes.yaml 中引用该概念的路径）

## 例外

以下情况允许名词性较弱但仍作为核心概念：
- 全书基石概念（如"电磁兼容"——无合适分类词可加）
- 标准化的专有名词（如"BLT方程"——方程本身就是分类词）
