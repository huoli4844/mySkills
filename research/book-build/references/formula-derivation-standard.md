# 公式推导标准（六步结构）

每个显示公式必须从物理原理出发逐步推导，禁直接贴结果。

## 六步推导结构

| 步骤 | 标签 | 内容要求 | 常见缺陷 |
|:----|:-----|:---------|:---------|
| ① 物理原理 | 原理 | 说明公式基于的物理定律/原理/定理 | 无来源、凭空出现 |
| ② 建模假设 | 假设 | 列出简化条件（远场/各向同性/TEM模/无损等） | 无假设说明 |
| ③ 原始方程 | 方程 | 写出积分律/微分方程/定义式 | 直接从结果出发 |
| ④ 数学代入 | 代入 | 代入物理量/参数/边界条件 | 跳步、缺中间量 |
| ⑤ 导出结果 | 结果 | 带编号的最终公式 `\tag{9-X}` | 漏编号、无编号 |
| ⑥ 参数解释 | 式中 | 逐变量说明含义+单位 | 无"式中"或解释不完整 |

## 实战实例

### 实例1：基本方程 M=P-S（第9章实战修正）

```
① 物理原理：电磁干扰三要素原理——骚扰源、耦合途径、敏感设备
② 建模假设：单骚扰源作用于单敏感设备，功率表示
③ 原始方程：P(t,f,θ,r) = G(t,f,θ) · T(t,f,θ,r)     ← 式(9-1)
④ 数学代入：G为源函数，T为传输函数
⑤ 导出结果：M(t,f,θ,r) = P(t,f,θ,r) - S(t,f,θ)      ← 式(9-2)
⑥ 参数解释：M-干扰裕度(dB), P-到达功率(dBm), S-敏感度阈值(dBm)
```

### 实例2：自由空间传播损耗（第9章实战修正）

```
① 物理原理：Friis传输方程（球面波扩散）
② 建模假设：各向同性辐射源、远场区、无损介质
③ 原始方程：功率密度 S = P_t / (4πr²)
④ 数学代入：接收天线有效面积 A_e = λ²/(4π)
   → P_r = S · A_e = P_t · λ² / (4πr)²
⑤ 导出结果：L_bf = 10lg(P_t/P_r) = 20lg(4πr/λ)      ← 式(9-4)
⑥ 参数解释：r-距离(m), λ-波长(m)
```

### 实例3：接收机灵敏度（第9章实战修正）

```
① 物理原理：热噪声 + 噪声系数定义
② 建模假设：标准温度 T₀=290K、白噪声
③ 原始方程：kBT₀ = 1.38×10⁻²³ × 290 ≈ 4×10⁻²¹W = -174dBm/Hz
④ 数学代入：噪声密度 -174+NF → 带宽内总噪声 (-174+NF)+10lgB
⑤ 导出结果：S_min = -174 + NF + 10lgB + SNR_min        ← 式(9-6)
⑥ 参数解释：NF-噪声系数(dB), B-带宽(Hz), SNR_min-最小信噪比(dB)
```

### 实例4：串扰模型（第9章实战修正）

```
① 物理原理：互容耦合 + 互感耦合
② 建模假设：电短耦合(l≪λ/4)、弱耦合、TEM传输
③ 原始方程：容性电流 I_C = C_m·dV_s/dt
             感性电压 V_L = L_m·dI_s/dt
④ 数学代入：近端容性 V_{N,C} = (1/4)k_C·V_s
             近端感性 V_{N,L} = (1/4)k_L·V_s
             远端容性 V_{F,C} = (1/4)k_C·V_s
             远端感性 V_{F,L} = -(1/4)k_L·V_s
⑤ 导出结果：V_{NEXT} = (k_C+k_L)V_s/4                    ← 式(9-21)
             V_{FEXT} = (k_C-k_L)·l/v·dV_s/dt             ← 式(9-22)
⑥ 参数解释：k_C=C_m/C(容性耦合系数), k_L=L_m/L(感性耦合系数)
```

## 审计规则

**Phase 4.5 新增检查项**：每章抽检5个关键公式，确认包含至少①+⑤+⑥三步。

```bash
# 推导深度快速检查
# 1. 定位公式
grep -n 'tag{' output/第N章.md | head -10
# 2. 查看公式前一段是否有推导标记
sed -n '$((LINE-3)),${LINE}p' output/第N章.md
# 推导标记词：推导、原理、根据、由、考虑、代入、可得
# 若无推导标记且无物理背景说明 → 标记为推导缺陷
```

**判定标准**：
- ✅ 通过：①+⑤+⑥齐全（含物理原理+导出结果+参数解释）
- ⚠️ 警告：缺少①（物理原理）或⑥（参数解释）
- ❌ 缺陷：直接贴结果，无任何推导文字
