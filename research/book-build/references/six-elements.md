# 教材质量检查指南（完整版）

> 扩展版：在 6 要素检查基础上，新增章级模式检查、写作技巧检查、13维度自审评分。
> 版本: 2.0（对应 book-build v1.3.0）

## 一、章级元信息检查（新增）

每章开头必须包含以下两个元素：

| # | 元素 | 检查标准 | 典型违规 |
|:-:|:-----|:---------|:---------|
| 0a | **内容提要** | 1-2 段概括本章内容，解释"讲什么、为什么重要" | 直接以"## 1.1"开头，无内容提要 |
| 0b | **学习目标** | 5-7 条以可验证动词开头的具体目标 | 写成抽象的"本章介绍了..."；目标不可验证 |

### 内容提要模板

```markdown
## 内容提要

本章是{领域}的导引章节，主要介绍{内容概述}，使读者对{主题}有一个总体的了解。
```

### 学习目标模板

```markdown
通过本章学习，读者应达成以下学习目标：

1. 准确区分{A}和{B}两个核心概念，理解{C}关系
2. 掌握{D}的{E}个要素，能用{F}方法分析具体问题
...
```

## 二、教材质量 6 要素检查（核心）

| # | 要素 | 检查标准 | 典型违规 |
|:-:|:-----|:---------|:---------|
| 1 | **权威定义** | 引用国家标准/国际标准定义，多个权威并列后归纳共同点 | 只给一个定义就完事 |
| 2 | **直观引入** | 公式/技术内容出现前，先给物理直观或日常类比（1-2句） | 公式直接砸出来没有引子 |
| 3 | **有编号的公式** | 每个公式有 `\tag{章-序号}` 编号 | 公式裸着不编号 |
| 4 | **"式中"变量解释** | 每个公式后紧跟"式中"段落，解释每个符号含义和单位 | 公式后无变量解释 |
| 5 | **含数字的实例** | 具体数字代入计算或真实案例（如"90%事故率""40kV/m场强"） | "已知A=B求C"抽象表述 |
| 6 | **层次化习题** | 每章习题覆盖 L1概念+L2计算+L3综合+L4诊断四个层次 | 只有概念题或只有计算题 |

## 各内容类型的 6 要素要求

| 内容类型 | 必选要素 | 可选要素 | 说明 |
|:---------|:---------|:---------|:-----|
| 历史叙事型 | 含数字的实例、层次化习题 | 直观引入 | 无需公式和式中 |
| 概念解构型 | 权威定义、直观引入、含数字的实例、层次化习题 | — | 用多标准定义 |
| 原理推导型 | **全部6要素** | — | 最严格的类型 |
| 系统组成型 | 直观引入、含数字的实例、层次化习题 | 公式编号、式中 | 框图描述为主 |
| 分类枚举型 | 含数字的实例、层次化习题 | 直观引入 | 并列子主题，无需公式 |
| 工程案例型 | 直观引入、含数字的实例、层次化习题 | — | 问题→方案→实施→效果 |

## 要素在正文中的具体体现

### 1. 权威定义
```markdown
按国家标准 GB/T 4365—2003 的定义：{定义}。
国际电工委员会（IEC）的定义：{定义}。
美国电气电子工程师学会（IEEE）的定义：{定义}。
上述定义虽措辞不同但反映的都是{核心思想}。
```

### 2. 直观引入
```markdown
人离物体越远，就越难看清物体，甚至无法看见物体。
同样的道理，{系统}发现{目标}，也有一个距离的限制。
下面通过{方程}来分析。
```

### 3. 有编号的公式
```markdown
$$P_r = \frac{P_t G_t G_r \lambda^2}{(4\pi R)^2}\tag{2-1}$$
```

### 4. "式中"变量解释
```markdown
式中，P_r 为接收信号功率（W），P_t 为发射功率（W），G_t 为发射天线增益。
```

### 5. 含数字的实例
```markdown
假定某雷达作用距离为100km，发射功率为100kW...
计算得最大侦察距离约为316km...
```

### 6. 层次化习题
```markdown
1. 什么是电磁干扰？（L1概念）
2. 将2:1、10:1转换为分贝值（L2计算）
3. 已知A、B、C，求D并分析趋势（L3综合）
4. 某设备出现XX现象，分析原因（L4诊断）
```

## 三、章级完成度检查（新增）

每章写完后，除了逐节检查 6 要素，还需检查以下整章级别的元素：

| 检查项 | 必须/可选 | 验收标准 |
|:-------|:---------:|:---------|
| **本章总结** | 推荐 | 5-7 条带**粗体关键字**的要点列表，每条独立可读 |
| **三层次习题** | **必须** | 基础题(5-6题) + 进阶题(3-4题) + 思考题(1-2题)，编号 {章}-{序号} |
| **参考文献** | 推荐 | 标准格式：[序号]. 作者. 书名[M]. 出版社, 年份. |
| **深入阅读** | 可选 | 带一句推荐语的扩展书目，与参考文献区分开 |

### 本章总结模板

```markdown
## 本章总结

1. **{概念A}**是{一句话定义}，**{概念B}**是{一句话定义}，{关系}。
2. 任何{问题}必须同时具备**{三要素}**{要素A}、{要素B}、{要素C}。
3. {概念C}分为**{子类A}**（{定义}）和**{子类B}**（{定义}）。
4. {领域}从{起始年}{起始事件}至今已逾{X}年。标志性事件：{事件A}（{年}）、{事件B}（{年}）。
```

### 三层次习题规则

| 层级 | 题量 | 认知要求 | 示例 |
|:----|:----:|:---------|:-----|
| **基础题** | 5-6 题 | 概念复述、术语直答 | `1-1 试述A与B的区别。` |
| **进阶题** | 3-4 题 | 多步推理、数值计算 | `1-8 某设备...计算是否满足标准？` |
| **思考题** | 1-2 题 | 联系实际、资料查阅 | `1-11 用三要素分析日常设备。` |

## 四、写作检查速查（Phase 3.12 模式对应表）

| 模式 | 所在位置 | 检查项 |
|:-----|:---------|:-------|
| 多标准并列定义 | 核心概念丨绪论 | [ ] 引用 ≥3 个标准？[ ] 归纳共同点？[ ] 提取条件？ |
| 概念关系形式化 | 成对概念辨析 | [ ] 数学符号表达因果？[ ] 用 `\\xrightarrow{}` 符？ |
| 概念对比表 | 相似概念区别 | [ ] ≥5 个对比维度？[ ] 维度名直接对立？[ ] 标"表 N-M"？ |
| 发展历程三阶段 | 历史类内容 | [ ] 分阶段命名？[ ] 国际/国内分写？[ ] 对照表收束？ |
| Mermaid→文字深解 | 5-15 子主题综述 | [ ] 先给总览图？[ ] 逐项 ≥150 字？[ ] 映射表收束？ |
| 工具/方法深度处理 | 工程工具节 | [ ] 定义→便利→换算→例题→速查→图示全链条？[ ] 例N-N格式？ |
| 教学信号词 | 全章分散 | [ ] 混淆预警？[ ] 要点重述("即：")？[ ] 理解锚点？[ ] 总起收拢？ |

## 五、综合核验清单

```
□ 0a 内容提要 (章首)
□ 0b 学习目标 (章首，5-7条)
□ 1 权威定义 (多标准并列)
□ 2 直观引入 (第一段不是公式)
□ 3 有编号的公式 (\tag{N-M})
□ 4 "式中"变量解释 (紧跟公式)
□ 5 含数字的实例 (具体数字)
□ 6a 本章总结 (章末，5-7条)
□ 6b 三层次习题 (基础+进阶+思考)
□ 6c 参考文献 (标准格式)
□ Mermaid 有图必有文字说明
□ 公式 LaTeX 语法合法（花括号平衡）
□ 无 KB 模板泄漏（"精准释义"等）
□ 跨章引用 ≥3 处
□ 案例教训提取（每个案例有启示段）
□ 教学设问过渡（节间≥2处）
□ 措辞独立率 >80%
```
