## 标准工作流

### Step 1: 确认需求
读写作指南 (`output/写作大纲/writing-guide-chN.md`) 确认各节需要的柯金良素材。

### Step 2: 定位柯金良内容
```bash
# 搜索章节起始行（先在 content_list.json 或直接搜索）
grep -n "^# 第 10 章\|^# 第 11 章\|^# 第 12 章" "处理后/电磁兼容概论_柯金良/优先级3-电磁兼容概论-柯金良.md"
grep -n "^## 10\.5\|^## 11\.2\|^## 12\.3" "处理后/电磁兼容概论_柯金良/优先级3-电磁兼容概论-柯金良.md"
```

然后用 `read_file(offset=, limit=)` 只读取目标块。例如柯金良§10.5的模型参数表在大约L15874~L15998。

### Step 3: 读现有章节
`read_file("output/第N章-标题.md", offset=, limit=)` — 只读插入点附近区域。

### Step 4: 用 patch() 插入
```python
# patch() 参数原则：
# 1. old_string 包含5-8行context确保唯一匹配
# 2. 包括插入点前后的标题行
# 3. new_string 包含 old_string 的全部内容 + 新增内容
# 4. 新增内容保持与现有章节一致的格式风格
```

### Step 5: 质量检查
```bash
python3 scripts/post_generation_check.py output/第N章-*.md --fix
python3 scripts/fix_common_issues.py output/第N章-*.md
```

### Step 6: 手动验证编号连续性
patch 插入后，手动检查：
- 新增公式的 `\tag{N-X}` 在 `$$...$$` 内部
- 公式编号未产生重复
- 图号、例题号未产生重复或跳跃

## 常见陷阱

1. **patch context 太短导致多次匹配** — 长章节中短段落后通常重复出现多次。提供5-8行context，包含前后的标题行。

2. **插入后公式编号不连续** — 在现有公式之间插入新公式后，后续编号全部偏移。patch 本身不会自动重排公式编号，需运行 `post_generation_check.py --fix` 进行修复。

3. **柯金良公式的LaTeX转义** — 柯金良源文件使用 `\\\\mathrm` 等四反斜杠格式，直接复制时注意保留。本教材使用 `\\mathrm` 双反斜杠。

4. **post_generation_check.py --fix 无法处理跨公式块的 `\tag{6-N}` 标签** — 柯金良章节中有大量从第6章引用的交叉引用标签（如 `\tag{6-1}` 放在两个 `$$...$$` 块之间而非内部）。运行 --fix 时，脚本会：① 补新编号（如 `\tag{6-26}`），但补在 `$$` 块外部；② 无法将已有 `\tag{6-1}` 等引用标签移入 `$$` 块内部。**修复方法**：在 blockquote 上下文中产生的孤立 tag 行，运行 `grep -n '^\\tag{'` 找到后手动删除不在 `$$` 内部的孤立 tag 行，然后运行 `renumber.py`。

5. **写入blockquote内公式的LaTeX转义** — 在 `> ` 引用的 blockquote 上下文中写 `$$...$$` 公式块时，patch 工具可能在 `\\mathrm{c}` 等转义序列上产生额外反斜杠（如 `\\mathrm{c}` → `\\\\mathrm{c}`）。写入后必须检查 blockquote 中的 LaTeX 转义是否完好。
