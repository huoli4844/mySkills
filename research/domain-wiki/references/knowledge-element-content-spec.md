# Knowledge Element Content Spec (知识要素内容生成指南)

知识要素（KE）是独立可复用的公式/方法/规则/工具，回答"用什么"。每个 KE item 必须完整填充所有 body 字段。

## 字段填充规则

| 模板变量 | 内容要求 | 必须填？ | 来源 |
|---------|---------|:-------:|:----:|
| `name` | 知识要素名称 | **必需** | — |
| `definition` | 定义/描述——该知识要素的核心说明（至少100字，含物理意义解释） | **必需** | 正文+推理 |
| `domain` | 学科/领域（如"电磁兼容"） | **必需** | 正文 |
| `classification` | 分类——该知识要素的类型（参数/常量/公式/指标/方法/工具/规则），含分类说明 | **必需** | 推理 |
| `structure` | 公式/表达式——用 `$$...$$` LaTeX 格式写出核心公式（如果是公式/方程类KE），否则填描述 | **必需** | 正文 |
| `key_parameters` | 参数说明——公式中各参数的名称、符号、单位、物理意义（用表格） | **必需**（如有公式） | 正文+推理 |
| `features` | 物理含义——该知识要素的物理意义、适用条件、限制（至少100字） | **必需** | 正文+推理 |
| `application_scenarios` | 应用场景——在哪些场景中使用该知识要素（至少3项，每项含具体说明） | **必需** | 正文+推理 |
| `value` | 使用价值——该知识要素的实际用途和效益（至少50字） | **必需** | 推理 |
| `upstream_downstream` | 关联概念——引用该知识要素的concept/KE wikilink（至少2条） | **必需** | 推理 |
| `related_knowledge_elements` | 关联知识要素——其他相关的KE wikilink，无则填"无" | 推荐 | 推理 |
| `references` | 参考资料——出处章节、标准文献，无则填"无" | 推荐 | 正文 |
| `source` | 出处原文引用，无则填"无" | 推荐 | 正文 |

## 内容质量标准

| 标准 | 通过条件 |
|:-----|:---------|
| 非空子节数 | 至少8个 `###` 子节有实质内容 |
| 总字数 | ≥ 1500 字符 |
| LaTeX公式 | ≥ 1（公式/方程类KE必须有） |
| 参数表格 | ≥ 1（公式类KE） |
| wikilink数 | ≥ 2 |

## 生成检查清单

- [ ] `definition` 至少100字
- [ ] `structure` 含正确LaTeX公式（公式类KE）
- [ ] `features` 说明物理意义和适用条件
- [ ] `application_scenarios` 至少3项
- [ ] "无"字段数 ≤ 3个
- [ ] wikilink 路径格式正确
