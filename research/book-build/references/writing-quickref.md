## 多标准并列定义

```
国家标准 GB/T 4365—2003《电工术语 电磁兼容》对{概念}的定义与 IEC 60050-161 一致：{定义}。

美国电气电子工程师学会（IEEE）的定义是：{定义}。

国家军用标准 GJB 72A—2002 的定义更加直接：{定义}。
```

然后归纳：`上述{数量}个定义虽措辞不同，但反映的都是同一个核心要求——{归纳}。`
再提取条件：`EMC包含两个基本条件：条件一...条件二...两个条件缺一不可。`

## 概念形式化（因果关系）

```
{A}与{B}的因果关系可以形式化描述为：

$$\text{EMD} \xrightarrow{\text{通过耦合途径作用于敏感设备}} \text{EMI} \tag{1-1}$$

即：{A}是原因、是现象；{B}是结果、是后果。
```
