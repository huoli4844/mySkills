# 各内容类型完整写作示例（多教材融合版）

> 本文件已依据**多教材融合写作法**（张亮视角→梁振光视角→路宏敏视角）更新。
> 更详细的融合模板见 `chapter-writing-standard.md` §3.3。
> 以下使用真实EMC领域示例。

## 1. 概念/定义类（适用：EMD/EMI定义、EMC定义等）

### 模板结构

```
第1段【张亮视角】：从日常现象切入
第2-3段【梁振光视角】：系统定义+多标准并列+对比表
第4-6段【路宏敏视角】：详实工程技术案例+事故分析+教训提炼
```

### 完整示例

```markdown
#### （1）电磁干扰定义

打开电视机时，室内的日光灯会出现瞬间变暗的现象——大量电流流向电视机，
电压骤然下降，利用同一电源的日光灯受到影响。这些日常经历背后，是
同一个工程问题——电磁干扰。

电磁干扰（EMI）是指电磁骚扰引起的设备、传输通道或系统性能的下降。
我国国家军用标准GJB 72A—2002的定义更加直接：任何能中断、阻碍、降低
或限制通信电子设备有效性能的电磁能量。这里需要区分两个本质不同的概念：
电磁骚扰（EMD）强调"可能性"——某种电磁现象具有潜在危害但不一定已
造成实际损害；电磁干扰（EMI）强调"实际后果"——性能下降已经发生。

1969年11月14日，美国土星V火箭运载的"阿波罗"12号飞船升空36.5秒时，
两道闪电击中了火箭，飞船的导航系统失效、飞行平台失控。事后分析表明：
火箭及其火焰形成的导电体（总长约300m）人为诱发了雷电，火箭顶端和
地面之间的电场高达2×10⁶V/m。这一案例揭示了重要教训：当大型导体穿越
强电场环境时，可能成为雷电的"触媒"。
```

## 2. 框架/要素类（适用：电磁干扰三要素）

### 模板结构

```
第1段【张亮视角】：从已讲案例中自然提炼框架
第2-4段【梁振光视角】：逐一列出要素+详细解释+数学模型
第5段【路宏敏视角】：多场景分析表验证
```

### 完整示例

```markdown
#### （2）电磁干扰三要素

从上面的手机-收音机例子可以看出，一个电磁干扰事件涉及三个"角色"：
发出电磁能量的（手机）、被干扰的（收音机）、以及能量传播的通道（空间）。
这就引出了电磁兼容分析中最核心的框架——电磁干扰三要素。

任何电磁干扰的产生，必须同时具备三个基本条件。第一，电磁骚扰源——
产生电磁能量的设备或自然现象。不同骚扰源有不同的特性：数字时钟是
周期性脉冲，频谱呈离散谱线分布；静电放电是单次瞬态脉冲，频谱连续。
第二，耦合途径——能量传输的通道，分为传导耦合和辐射耦合。第三，
敏感设备——对骚扰产生响应的设备。三要素之间满足定量关系：
E_int(f) = S(f) · C(f)，当 E_int(f) ≥ R_th(f) 时干扰发生。

表1-2列出了5个典型场景的三要素分析。例如在手机靠近CRT显示器的场景中：
骚扰源为手机射频发射，耦合途径为空间辐射，敏感设备为CRT显示器，
干扰表现为图像抖动。对应策略可以是增大距离或加装屏蔽。
```

## 3. 历史叙事类（适用：EMC学科发展）

### 模板结构

```
第1段【张亮视角】：说明了解历史的价值
第2-8段【路宏敏视角】：分阶段详实叙事
  → 每条事件必须包含：年份+组织全称(含英文)+具体日期+经过+意义
  → 禁止"1933年CISPR成立"式概括写法
  → 必须写"1933年，国际无线电干扰特别委员会（CISPR...）在巴黎成立。"
第9段【梁振光视角】：对照表收束
```

### 完整示例

```markdown
### 1.2.1 国际的电磁兼容发展

了解电磁兼容的发展历程，有助于理解当前EMC标准体系和设计方法的形成
逻辑——它们不是某一天突然产生的，而是在一次次事故教训中逐步积累起来的。

【萌芽探索期：19世纪末—20世纪30年代】

1881年，英国科学家希维赛德（Oliver Heaviside）发表了题为"论干扰"
（On Interference）的论文，这是人类历史上第一篇有意识研究电磁干扰
问题的学术文献。1888年，德国物理学家赫兹通过火花隙实验成功产生和
接收了电磁波，验证了麦克斯韦的电磁场理论。

1933年，国际无线电干扰特别委员会（CISPR——Comité International
Spécial des Perturbations Radioélectriques）在法国巴黎成立。CISPR
第一次会议于1934年6月28日至30日在巴黎召开。CISPR的成立标志着电磁
干扰问题从个别工程师的经验判断上升为国际组织的标准化协作。

| 年代 | 国际重要事件 |
|:----:|:-------------|
| 1881 | 希维赛德发表"论干扰" |
| 1933 | CISPR成立（1934年第一次会议） |
| 1944 | VDE 0878——首个EMC规范 |
| 1964 | IEEE Trans. on EMC创刊（学科形成标志） |
| 1996 | 欧盟EMC指令强制执行（全球转折点） |
```

## 4. 内容综述类（适用：EMC研究内容）

### 模板结构

```
第1-2段【梁振光视角】：狭义vs广义区分 + Mermaid总览图
第3-12段【路宏敏视角】：每项2-4段详述（原理+实例+前沿）
第13段【梁振光视角】：映射表收束
```

### 完整示例

```markdown
## 1.3 电磁兼容研究内容

电磁兼容的研究内容可以从狭义和广义两个层面来理解。从狭义概念出发，
EMC是围绕电磁干扰三要素展开的技术研究。从广义概念出发，EMC已发展
为涵盖电磁场理论、电路与系统、材料科学、生物医学等多学科交叉的系统
工程。

① 电磁干扰特性及其传播理论。这是EMC学科最基础的研究方向。研究内容
包括电磁骚扰源的时域和频域特性分析——例如脉冲波形的傅里叶级数表示、
ESD脉冲的双指数波形模型、数字时钟谐波的频谱分布。

② 电磁危害及电磁频谱管理。电磁辐射已被列为第五种公害。频谱管理由
国际电信联盟（ITU）全球协调，我国由中国无线电管理委员会负责。

（其余7项类似展开……）

| 研究领域 | 核心问题 | 与三要素的关系 | 支撑学科 |
|:---------|:---------|:-------------|:---------|
| 干扰特性 | 如何产生和传播 | 源+途径 | 电磁场理论 |
| 危害与频谱 | 如何防控 | 源（环境视角） | 环境科学 |
```

## 5. 各内容类型速查表

| 类型 | 张亮要素 | 梁振光要素 | 路宏敏要素 | 必须避免 |
|:-----|:---------|:-----------|:-----------|:---------|
| 概念定义 | 日常现象引入 | 多标准并列+对比表 | 案例+技术分析 | "你"、"Step N" |
| 框架要素 | 从已讲案例提炼 | 列表+数学模型+式中 | 多场景验证表+策略 | 孤立定义框 |
| 历史叙事 | 开头说明历史价值 | 对照表收束 | 全称+日期+年份+分析 | 概括式写法 |
| 内容综述 | 穿插工程实例 | 狭义广义区分+总览图 | 每项2-4段详述 | 点到为止式列举 |
| 特点归纳 | — | 开头总起段 | 逐条展开+工具全链条 | 只有条目无解释 |
