# v43.1 nested 布局重构

## 改动背景

用户要求自定义领域名（如「电磁兼容领域」）和书籍编号（如「0001_电磁兼容基础教材」），不再使用旧的 `01_领域/01_资料库/{book_id}` 三层容器目录。

## 新目录结构

```
kb_root/
├── 知识库总控/                  ← L4
├── {domain_name}/               ← 领域名直接作为目录名
│   ├── 领域总控/                ← L3
│   └── {book_id_and_name}/      ← 如 0001_电磁兼容基础教材
│       ├── 10_总揽/             ← L2
│       ├── 20_正文/
│       ├── 30_核心概念/
│       ├── 40_知识要素/
│       ├── 50_知识点/
│       ├── 60_技能点/
│       ├── 70_应用场景/
│       ├── 80_实体/
│       └── .dag/
```

## DIR 常量变化

| 键 | 旧值 | 新值 |
|:---|:----|:----|
| KE | `30_知识要素` | `40_知识要素` |
| KP | `40_知识点` | `50_知识点` |
| SP | `50_技能点` | `60_技能点` |
| SCENE | `60_应用场景` | `70_应用场景` |
| ENTITIES | `70_实体` | `80_实体` |
| DOMAIN_CTRL | `00_领域总控` | `领域总控` |
| KB_CTRL | `00_知识库总控` | `知识库总控` |
| FIELD | `01_领域` | `""` (由目录结构推导) |
| LIBRARY | `01_资料库` | `""` (由目录结构推导) |

## 布局检测

`detect_layout(wr)` 优先检查 `wr/20_正文/` 存在 → nested → kb_root = wr/../..
