# Concept Content Spec (概念内容生成指南)

## 核心概念的三标准（v6.1 强化）

> ⚠️ **第一原则：只有正文中长篇大论教授的知识才是核心概念**
>
> 核心概念必须同时满足三条量化标准：
> 1. **篇幅 ≥ 50 行** —— 需要长篇讲授，不是一句话能说清的。**正文中只提了一下的内容（<30行）绝不能升级为核心概念**
> 2. **支撑材料 ≥ 3 个** —— 包含公式 + 图 + 表 合计至少 3 个
> 3. **有展开结构** —— 含子标题或多个独立段落，不是单一定义
>
> **反面示例**：正文中"频率管理"一词出现在 §8.1 的行文中可能只有几句话提到，虽然 Agent 可以围绕它生成 5KB 的内容，但源文并未长篇教授——此类应降级为知识要素(KE)。
>
> **正面示例**："电磁兼容三要素"在 §1.1.2 展开讲授 120+ 行，含图1-1、公式、分类表——满足三标准。
>
> 不满足以上三条的术语 → **不写入 concepts.yaml**，归入知识要素（KE）。

## v6.1 字段等级调整
>
> 行号范围从哪里来？先读 `.dag/第N章/chapter_toc.json`（由 `preprocess_toc.py` 自适应探测容器层级 + 超大节段分割），
> 按 `containers[]` 数组逐个 `read_file(offset=line, limit=line_end-line)`，只读该容器的精准节段。对 `auto_split` 容器，遍历 `split_into[]` 子容器。
> 容器外的内容（另一个容器节段中的图/公式）不得写入当前概念的 fields。

生成概念 JSON items 时，每个 item 必须完整填充所有 body 字段。**禁止除"无"之外的任何空节**——所有字段必须有实质性内容。下表列出每个 template body 变量应填的内容。

## 自适应容器原则（v36.5）

容器层级**由脚本自适应探测**（不硬编码 `###`）。`preprocess_toc.py` 统计每章各层级标题数和平均管辖行数，选择"标题数≥3 且平均行数 30-300"的最深层级作为容器层。超大无子标题节段自动分割为子容器。概念的所有支撑素材（图/公式/表/KE/实体）都位于该容器内。

**操作规则**：
1. Agent 先读 `chapter_toc.json` 中的 `containers[]` 数组和 `container_level`
2. 对每个容器（或 `auto_split` 的 `split_into[]` 子容器），用 `read_file(offset=line, limit=line_end-line)` **只读该容器所属的行范围**
3. 容器内出现的所有素材：
   - `$$...$$` → `formula_references`
   - `图X-X` → `figure_references`
   - `表X-X` → `additional_explanations`（不放入 `figure_references`）
   - `XX是指/称为...` → `definition_sentence`
   - `XX定理/XX参数/XX方程` → 知识要素候选（后续 kes.yaml）
   - `XX设备/XX材料` → 实体候选（后续 entities.yaml）
4. **严禁**将容器外的内容写入该概念的 YAML
5. 不在任何容器内的术语（如正文中偶尔提到的“干扰裕度”）→ 不是核心概念，是知识要素候选项

**验证方法**：每个概念写完后 `search_files("图X-X", path="30_核心概念/")` 交叉检查——同一图号不得出现在 ≥2 个概念文件中（特殊例外：图明确说明多种关联内容的，如"图1-2 电磁干扰示意图"同时展示辐射耦合和传导耦合）。

## 字段填充规则

| 模板变量 | 内容要求 | 必须填？ | 来源 |
|---------|---------|:-------:|:----:|
| `definition_sentence`（JSON中写作`definition`） | 精准释义——正文**逐字提取**（⚠️严格）。**规则**：（1）从"是指"/"称为"开始，**不包含概念名称**（如"是指设备在共同的..."而非"电磁兼容是指..."）；（2）完整句子+结尾标点，不可截断；（3）一字不差，前120字可在出处逐字检索到 | **必需** | 出处正文 |
| `term_english` | 英文术语（如`Electromagnetic Compatibility`） | **必需** | 正文或标准 |
| `term_definition` | 术语定义的展开/补充说明（1-3句，非逐字） | **必需** | 正文+推理 |
| `definition_source` | 出处标注，格式 `来源：第N章 §节号` | **必需** | 正文元数据 |
| `additional_explanations` | 定义后的额外解释段落（含出处标注），从正文提取补充，至少1段 | 推荐 | 正文 |
| `formula_references` | **正文中的公式引用（与该概念严格相关）**——扫描概念定义所在段落前后，正文中可能有公式。**但只有以下条件同时满足时才能纳入**：（1）公式出现在正文中**直接描述该概念的段落内**（同一节/同一段落组）；（2）公式的变量/参数/符号在正文中明确为该概念的解释服务；（3）公式与概念存在直接的因果/定义/计算关系（如"电磁兼容三要素"不能用"分贝换算公式"）。不满足则填"无"。⭐ **关键判断**：该公式去掉之后，对该概念的解释是否会不完整？如果不会，说明该公式不是该概念的核心公式，不纳入。格式：**必须包含 `$$...$$` 块级 LaTeX 公式**。**禁止纯文本跨引用**（如"参见XX条"），此类应放入 `additional_explanations`。`formula_references` 只有两种合法格式：（a）含 `$$...$$` 的 LaTeX 公式块；（b）`无`。包含无 `$$` 的文本描述均违规。 | **推荐** | 正文节内匹配 | ⚠️ 禁止跨节提取公式。图1-1的干扰裕度公式属于知识要素"电磁兼容预测基本方程"而非"电磁兼容"概念的数学模型，后者无公式。另见 ### 容器原则——公式在哪个 ### 容器内就属于哪个概念。 |
| `figure_references` | **正文中的插图引用（仅限直接解释该概念的图）**——扫描概念定义所在小节，提取**只与该概念直接相关**的 `图X-X`。判断标准：（1）正文中该图的说明文字（图题行）是否包含该概念名称或直接描述了该概念；（2）图的引用文字（如"如图X-X所示"）是否出现在**明确描述该概念的句子中**。如果图是展示一组概念的（如三要素图同时展示3个概念），则**只对主概念填写**。如果 assets 中有对应图片文件，**必须用 `![图X-X 标题](相对路径/文件名)`**；否则用 `> 图X-X 标题` blockquote。无专有插图时填"无"。**禁止在 figure_references 中出现表引用**——表属于 additional_explanations。 | **条件必需** (v6.1↑) | 正文节内+assets+容器定位 | ⚠️ 强制规则：源文该概念容器内出现"图X-X"引用→必须纳入概念文件。图片嵌入在 `### 1. 工作原理/构成要素` 关键段落处（图文并茂） |
| `core_concept_map` | 核心概念图谱——Mermaid flowchart TD 图，展示该概念与相关概念的关系网络（至少5个节点，含颜色编码 classDef） | **必需** | 自主生成 |
| `core_concept_map_source` | 图谱来源标注，无则填"无" | 可选 | — |
| `core_concept_map_analysis` | **核心概念图谱解析**——对上面Mermaid图的**逐节点/逐边文字解释**（至少100字）。必须逐条说明：图中每个节点的含义、每条箭头的因果关系、颜色编码的含义。格式要求：用自然语言描述图的完整逻辑链，不能只是列点。示例："图中A节点代表X，A→B箭头表示Y，B节点代表Z..."。无图时填"无" | **必需** | 自主生成 |
| `structure` | 工作原理/构成要素——该概念的结构、工作机理、组成部分（至少100字） | **必需** | 正文+推理 |
| `mathematical_model` | 来自正文的数学模型（与该概念直接相关的数学描述）——从正文中提取直接描述该概念的数学关系。仅当正文同一节内存在专为该概念服务的数学推导/公式组时才填写。判断标准：该数学关系在正文中的上下文是否以该概念的名称为主语（如"XXX的数学模型为..."）。如果没有则填"无"。格式：含 $$...$$ LaTeX 公式 + 参数说明 | **条件必需** (v6.1↑) | 正文节内匹配 | ⚠️ IM = P_I - S_I 是"干扰裕度"知识要素的公式，不属于"电磁兼容"概念的数学模型。强制规则：①若源文该容器内有公式/数学表达式→必须用 `$$...$$` LaTeX，禁止纯文本；②概念名称含"方程/模型/计算/定理"且源文有公式→不得填"无" |
| `tech_classification` | 技术分类——该概念的类别、子类、分支体系（至少3项，用列表），无则填"无" | 推荐 | 正文+推理 |
| `application_scenarios` | **应用场景（含详细说明）**——该概念在实际中的使用场景列表。**每项必须是一条完整说明**，格式为 `- **场景标题**：场景描述（至少50字），包含：场景背景（在什么情况下出现）、解决的问题（该概念如何应用其中）、关联分析（与该概念原理的对应关系）。禁止只有标题没有详细说明（如\"PCB走线串扰分析\"这样裸标题是不允许的）。每个概念建议2-4个场景。示例：`- **PCB走线串扰分析**：在高密度PCB设计中，相邻走线之间的寄生电容和互感会产生传导耦合，导致信号质量下降。传导耦合理论用于建立走线间距与串扰量之间的数学模型，指导PCB布局布线规则设计。` | **必需** | 正文+推理 |
| `typical_systems` | 典型系统——应用该概念的系统/设备示例，无则填"无" | 推荐 | 正文+推理 |
| `related_equipment` ~~（已移除）~~ | — | — | — |
| `related_concepts_relations` | 与相关概念的关系——该概念与上下游/关联概念的联系说明（至少2条，每条含 wikilink） | **必需** | 正文+推理 |
| `evolution` | 发展/演进——该概念的历史发展、研究趋势（至少50字），无则填"无" | 推荐 | 推理+搜索 |
| `engineering_practices` | 工程实践要点——实际工程中的注意事项、设计原则（至少2条，每条30字以上） | **必需** | 推理 |
| `common_misconceptions` | 常见误区——对该概念的常见误解/错误认识（至少1条，含解释） | **必需** | 推理 |
| `references` | 参考资料——该概念相关的标准、文献引用，无则填"无" | 推荐 | 正文+搜索 |
| `related_knowledge_elements` | 使用到的知识要素 wikilink（1+条） | **必需** | 推理 |

## v6.1 新增：概念类型分类策略

根据源文章节性质，概念分为两类，对「数学模型」「关键参数」「技术分类」等理论性子节实行差异化要求：

### 理论型概念
- **特征**：源文章节含原理/理论/模型/方程/推导
- **示例**：麦克斯韦方程、电磁辐射基本模型、金属平板屏蔽效能的计算
- **强制**：`mathematical_model` 不得为「无」（源文有公式时必须用 `$$...$$` LaTeX）
- **强制**：`key_parameters`、`features`、`tech_classification` 必须有实质内容

### 方法型概念
- **特征**：源文章节含测量/测试/检测/试验/防护/管理
- **示例**：辐射发射测量、电磁兼容现场测量、雷电防护、频率管理
- **放宽**：`mathematical_model`、`key_parameters`、`features`、`tech_classification` 可填「无」
- **强制**：`application_scenarios` ≥ 3 个，每场景 ≥50 字
- **强制**：`engineering_practices` ≥ 3 条
- **强制**：`common_misconceptions` ≥ 2 条

## v6.1 新增：定义句降级策略

当源文没有显式的「XX是指/称为」完整定义句时：

| 优先级 | 策略 | confidence |
|:---:|------|:---:|
| P1 | 源文有完整定义句 → **逐字提取** | 0.95 |
| P2 | 源文有多句分散描述 → 提取最核心一句 + `additional_explanations` 补充其余 | 0.85 |
| P3 | 源文无显式定义（复合概念如「电磁兼容三要素」）→ `definition_sentence` 引用最相关原文片段（`> 原文: "..."` 格式），`term_definition` 写自主综合（标注「综合自 §X.X.X」） | 0.85 |

## v6.1 新增：公式/LaTeX 强制规则

> ⚠️ **mathematical_model 中所有数学表达式必须用 `$$...$$` 块级 LaTeX。纯文本公式（如 `dB=10lg(P1/P0)`）被视为格式违规。**

- 正确：`$$\mathrm{dB}=10\lg\frac{P_1}{P_0}$$`
- 错误：`dB=10lg(P₁/P₀)`（纯文本，无 LaTeX 包裹）
- Mermaid 图节点文本中也**禁止**出现纯文本公式——节点只放概念名

Agent 在写 YAML 前必须执行的公式提取步骤：
1. `search_files("$$", path="20_正文/第N章.md")` 找到所有 `$$` 标记
2. 判断每个 `$$` 块是否位于当前概念的容器行号范围内
3. 在范围内的 → 填入 `mathematical_model`（保持 `$$...$$` 格式）
4. 不在任何 `$$` 块但源文有关键数学描述（如 `∇×E = -jωμH`）→ 改写为 LaTeX `$$\nabla\times\mathbf{E} = -j\omega\mu\mathbf{H}$$`
5. 概念名含「方程/模型/计算/定理」且源文有公式 → mathematical_model **不得填「无」**

## 不再渲染的字段

`source`（出处全文引用）在 v5.2 模板中已移除 `### 出处` 节，不再渲染到 MD 文件。出处信息现通过 `definition_source` 的 `> 来源：...` blockquote 展示。`source` 仍保留在 YAML 数据层供溯源，新章无需再填此字段。

## 与 emc-textbook-wiki 的差异

domain-book-wiki 的 template 使用 body 变量（`{{变量名}}`）而非直接 Markdown 子节。因此生成 JSON items 时，所有 body 字段的值直接对应模板中的 `{{变量名}}`。填充规则与 emc-textbook-wiki 的 5 层结构一一对应：

| template body 变量 | 对应 emc 5层结构 |
|-------------------|-----------------|
| `term_english`, `term_definition`, `definition_sentence`, `additional_explanations` | 一、基础层 |
| `structure`, `mathematical_model`, `tech_classification` | 二、解析层 |
| `application_scenarios`, `typical_systems` | 三、应用层 |
| `related_concepts_relations`, `confusion_compare`, `evolution` | 四、关联层 |
| `engineering_practices`, `common_misconceptions`, `references` | 五、补充层 |

---

> ⚠️ **质量底线**：任何字段不得填"无"除非该概念确实无此方面内容（如简单概念无数学模型）。批量生成后运行 `pipeline validate` 确认所有概念通过定义验证 + 内容深度检查。

> ⚠️ **关键举例——图/公式/数学模型必须严格属于当前概念**：
> 
> 以第1章为例：
> - **图1-1 电磁干扰三要素**：是"三要素"整体的示意图，✓ 只对"电磁兼容三要素"有效。✗ 对"电磁干扰源""耦合途径""敏感设备"无效——该图不是为了分别解释它们中的任何一个而画的
> - **图1-2 电磁干扰示意图**：展示多种耦合路径，✓ 对"辐射耦合""传导耦合"有效——图的文字说明"实际设备间发生的电磁干扰通常包含多种电磁耦合"在描述耦合过程。✗ 对"电磁兼容三要素"无效
> - **IM = P_I - S_I 公式**：是描述干扰裕度（属于知识要素"电磁兼容预测基本方程"）的数学关系，✗ 不属于"电磁兼容"概念的数学模型——正文§1.1.1对"电磁兼容"的定义段落中无此公式
> 
> 生成时请对每个概念逐一判断：这个图/公式在正文中出现的段落，主语是这个概念吗？如果段落主语是另一个概念，则图/公式不属于当前概念。
