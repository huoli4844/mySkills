# 章末固定模板



### 4.1 本章总结

6条要点，每条以**粗体关键字**开头，每条独立可读。

```
## 本章总结

1. **{概念A}**是{一句话定义}，**{概念B}**是{一句话定义}，{关系}。
2. 任何{问题}必须同时具备**{框架名}**：{要素A}、{要素B}、{要素C}。
3. {概念C}分为**{子类A}**（{定义}）和**{子类B}**（{定义}）。
4. {领域}从{起始年}至今{时间跨度}。**里程碑**：{事件A}（{年}）、{事件B}（{年}）。
5. {主题}的核心内容是{概述}。
6. {重要工具}是{领域}中最核心的{单位/概念}。{关键公式}。
```

### 4.2 习题（三层次）

| 层次 | 题量 | 认知要求 | 编号格式 |
|:----|:----:|:---------|:---------|
| 基础题 | 5-6题 | L1概念复述 | N-1 ~ N-6 |
| 进阶题 | 3-4题 | L2-L3计算+分析 | N-7 ~ N-10 |
| 思考题 | 1-2题 | L4开放+拓展 | N-11 ~ N-12 |

每道题标注 `（对应学习目标X，§N.N.N节）`。

### 4.3 参考文献 + 深入阅读

```
## 参考文献

1. {作者}. {书名（版次）}[M]. {出版地}：{出版社}，{年份}. 第{X}章
2. {标准号} {标准名称} [S]. {发布地}：{发布机构}，{年份}

## 深入阅读

1. {著者}. {书名}[M]. {出版社}，{年份}. —— {一句推荐语}
```
